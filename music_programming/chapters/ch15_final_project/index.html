    Lesson 15: 総合演習 — 作品制作¶

    このレッスンで学ぶこと¶

    • これまでの 14 回で学んだ知識を統合し、ひとつの作品にまとめる
    • Python コース（音の原理の深掘り）または Sonic Pi コース（音楽制作）から課題を選ぶ
    • 作品の構想から完成までのプロセスを体験する
    • 作品を発表し、互いにフィードバックを交わす

    Lesson 14 までで、音の仕組みを Python で探り、Sonic Pi で音楽として表現する一連の流れを学んできました。この最終レッスンでは、これまでの知識を自分なりに組み合わせて作品を作ります。

    15.1 課題の選び方¶

    最終課題は、以下の 2 コースから 1 つを選んで取り組みます。各コースにはテーマが 2 つあり、自分の興味に合うものを選んでください。

    コース テーマ 概要
    Python コース A. 音の分析と再現 楽器音をスペクトル分析し、加算合成で再現を試みる
    Python コース B. オリジナルエフェクトの設計 自分だけのエフェクトを設計・実装する
    Sonic Pi コース C. 既存曲のアレンジ 好きな曲を Sonic Pi で打ち込み、自分なりにアレンジする
    Sonic Pi コース D. ライブコーディング作品 展開のある構成を設計し、ライブパフォーマンスとして仕上げる

    どのテーマも、複数のレッスンの知識を組み合わせることがポイントです。1 つのレッスンで学んだ技術だけでは完成しません。

    15.2 Python コース¶

    テーマ A: 音の分析と再現¶

    楽器や声など「実際の音」をスペクトル分析し、その結果をもとに Python で音を再現します。分析と合成を行き来することで、「音色とは何か」を深く理解できます。

    使うレッスンの知識¶

    ステップ 内容 関連レッスン
    1. 素材を用意する WAV ファイルを読み込む Lesson 1
    2. スペクトル分析 FFT で倍音構成を読み取る Lesson 13
    3. 加算合成で再現 読み取ったレシピでサイン波を合成する Lesson 4
    4. エンベロープを付ける ADSR で音の立ち上がりと減衰を似せる Lesson 8
    5. 比較・考察 元の音と再現音のスペクトルを並べて評価する Lesson 13

    進め方¶

    ステップ 1: 素材を用意する

    分析したい音の WAV ファイルを用意します。フリーの楽器音サンプルを使うのが手軽です。

    from audio_lib import load_audio
from audio_lib.notebook import play_sound, plot_spectrum

# WAV ファイルを読み込む
original = load_audio("piano_c4.wav")
display(play_sound(original, "元の音"))

    ステップ 2: スペクトルを読み取る

    Lesson 13 で学んだ plot_spectrum() でスペクトルを表示し、どの周波数にどのくらいの強さのピークがあるかを読み取ります。

    plot_spectrum(original, max_freq=5000, title="元の音のスペクトル")

    スペクトルのピークから、基本周波数と各倍音の振幅比を表にまとめましょう。

    倍音次数 周波数 (Hz) 相対振幅
    1（基本音） 262 1.0
    2 524 ?
    3 786 ?
    ... ... ...

    ステップ 3: 加算合成で再現する

    読み取った倍音のレシピを additive_synth() に渡して音を合成します。

    from audio_lib import additive_synth

# スペクトルから読み取ったレシピ（例）
recipe = {1: 1.0, 2: 0.6, 3: 0.3, 4: 0.15, 5: 0.08}
reproduced = additive_synth(262, recipe, duration=1.0)
display(play_sound(reproduced, "再現した音"))

    ステップ 4: エンベロープで表情をつける

    加算合成だけでは音が平坦です。Lesson 8 の ADSR エンベロープを適用して、音の立ち上がりと減衰を似せましょう。

    from audio_lib import adsr

envelope = adsr(
    duration=1.0,
    attack=0.01,    # ピアノは立ち上がりが速い
    decay=0.3,
    sustain=0.4,
    release=0.3,
)
reproduced_with_env = reproduced * envelope
display(play_sound(reproduced_with_env, "エンベロープ付き"))

    ステップ 5: 比較する

    元の音と再現音のスペクトルを並べて、どこが似ていてどこが違うかを考察します。

    # 元の音のスペクトル
plot_spectrum(original, max_freq=5000, title="元の音のスペクトル")

# 再現した音のスペクトル
plot_spectrum(reproduced_with_env, max_freq=5000, title="再現した音のスペクトル")

    完全な再現は難しいはずです。「何が足りないか」を考えることが、この課題の核心です。たとえば、ピアノの音は時間とともに倍音のバランスが変化しますが、単純な加算合成ではそれを表現できません。こうした気づきが「音色の理解」につながります。

    提出物の目安¶

    • 分析・再現の Python コード（Colab ノートブック）
    • 元の音と再現音のスペクトル比較図
    • 考察（200〜400 字程度）: 何がうまくいき、何が再現できなかったか

    テーマ B: オリジナルエフェクトの設計¶

    Lesson 9 で学んだディレイ・リバーブ・コンプレッサーの原理を応用して、自分だけのエフェクトを設計・実装します。

    使うレッスンの知識¶

    ステップ 内容 関連レッスン
    1. エフェクトを選ぶ 作りたいエフェクトの仕組みを調べる Lesson 9
    2. 設計する 信号処理の流れを図にする Lesson 9
    3. 実装する Python で処理を書く Lesson 1, 9
    4. テスト音に適用 さまざまな音で試す Lesson 2, 4
    5. パラメータを調整 効果を聴きながらパラメータを探る Lesson 9, 13

    エフェクトの候補¶

    どんなエフェクトを作るかは自由ですが、以下にいくつか候補を挙げます。

    ビットクラッシャー（難易度: 低め）

    サンプリングレートやビット深度を意図的に下げて、荒い質感の音を作るエフェクトです。Lesson 1 で学んだサンプリングと量子化の知識が直接活きます。

    import numpy as np

def bitcrusher(data, bit_depth=8, downsample=4):
    """ビットクラッシャー: ビット深度とサンプリングレートを下げる"""
    # ビット深度を下げる（量子化を粗くする）
    levels = 2 ** bit_depth
    crushed = np.round(data * levels) / levels

    # ダウンサンプル（間引いて戻す）
    crushed[::downsample] = crushed[::downsample]  # 基準点
    for i in range(len(crushed)):
        crushed[i] = crushed[i - (i % downsample)]  # 直前の基準点の値を保持

    return crushed

    トレモロ（難易度: 低め）

    音量を周期的に揺らすエフェクトです。LFO（低周波発振器）の考え方を学べます。

    def tremolo(data, rate=5.0, depth=0.5, sr=44100):
    """トレモロ: 音量を周期的に変化させる"""
    t = np.arange(len(data)) / sr
    # LFO: 0〜1 の範囲で振動する波
    lfo = 1.0 - depth * (0.5 + 0.5 * np.sin(2 * np.pi * rate * t))
    return data * lfo

    ディストーション（難易度: 中程度）

    信号を意図的にクリッピングして歪ませるエフェクトです。波形の変化をスペクトルで観察すると、倍音が増えていく様子がわかります。

    リングモジュレーター（難易度: 中程度）

    入力信号にサイン波を掛け合わせるエフェクトです。元の音にない周波数成分が現れる、独特な金属的サウンドが得られます。

    進め方のポイント¶

    1. まず仕組みを理解することから始めましょう。「この処理をすると信号がどう変わるか」をブロック図で描いてみてください
    2. 実装は短いコードから始め、テスト音（サイン波など単純な音）で動作を確認します
    3. パラメータを変えたときに音がどう変わるかを試し、スペクトルでも変化を確認しましょう（Lesson 13）
    4. 最後に、メロディや楽器音など複雑な音にも適用してみてください

    提出物の目安¶

    • エフェクトの実装コード（Colab ノートブック）
    • 処理の流れを説明する図またはブロック図
    • 適用前後の音の比較（波形図やスペクトル図）
    • パラメータを変えたときの変化の説明（200〜400 字程度）

    15.3 Sonic Pi コース¶

    テーマ C: 既存曲のアレンジ¶

    好きな曲の一部を Sonic Pi で打ち込み、自分なりのアレンジを加えます。「聴いた音楽をコードで表現する」体験を通じて、音楽の構造を深く理解できます。

    使うレッスンの知識¶

    ステップ 内容 関連レッスン
    1. 曲を選ぶ 8〜16 小節程度の部分を決める —
    2. メロディを打ち込む スケールとノートで旋律を表現する Lesson 7
    3. コード（伴奏）をつける 和音進行を組む Lesson 7
    4. リズムを組む ドラムパターンを作る Lesson 12
    5. 音色とエフェクトで仕上げる シンセ・FX を選ぶ Lesson 5, 10
    6. アレンジする 自分なりの変更を加える 全体

    進め方¶

    ステップ 1: 曲と範囲を決める

    好きな曲のサビやイントロなど、8〜16 小節程度の部分を選びます。最初からフル尺を目指さず、短い範囲に絞るのがコツです。

    ステップ 2: メロディを打ち込む

    まずメロディだけを play と sleep で打ち込みましょう。Lesson 7 で学んだ :c4, :e4 などのノート表記を使います。

    use_bpm 120

live_loop :melody do
  use_synth :piano
  # 例: 「きらきら星」の冒頭
  notes =  [:c4, :c4, :g4, :g4, :a4, :a4, :g4]
  durs  =  [1,   1,   1,   1,   1,   1,   2  ]

  notes.zip(durs).each do |n, d|
    play n, amp: 0.7
    sleep d
  end
end

    ステップ 3: コードをつける

    Lesson 7 で学んだ chord を使って伴奏を加えます。

    live_loop :chords do
  use_synth :prophet
  # C → C → F → C の進行（例）
  chords = [(chord :c4, :major), (chord :c4, :major),
            (chord :f4, :major), (chord :c4, :major)]

  chords.each do |c|
    play c, release: 1.8, amp: 0.4
    sleep 2
  end
end

    ステップ 4: リズムを加える

    Lesson 12 のリズムパターンの技法で、ドラムパートを追加します。

    live_loop :drums do
  sample :bd_haus
  sleep 1
end

live_loop :hihat do
  sample :hat_snap, amp: 0.3
  sleep 0.5
end

    ステップ 5: 音色とエフェクトで仕上げる

    シンセの選択（Lesson 5）や with_fx（Lesson 10）で雰囲気を作り込みます。

    ステップ 6: 自分なりのアレンジを加える

    ここが一番大事なステップです。原曲どおりに打ち込むだけでは「コピー」ですが、何か自分なりの変更を加えることで「アレンジ」になります。たとえば：

    • テンポやスケールを変える（メジャー → マイナー）
    • リズムパターンを別ジャンルにする（ポップス → ボサノバ）
    • シンセやエフェクトで音色を大きく変える
    • メロディの一部を変奏する

    提出物の目安¶

    • Sonic Pi のコード
    • 元の曲名と、どの部分をアレンジしたか
    • アレンジのポイントの説明（100〜200 字程度）

    テーマ D: ライブコーディング作品¶

    Lesson 14 の技法を使い、「展開のある構成」を持つライブコーディング作品を設計・演奏します。

    使うレッスンの知識¶

    ステップ 内容 関連レッスン
    1. 構成を設計する 展開の台本（シナリオ）を考える Lesson 14
    2. 素材を用意する シンセ・サンプル・エフェクトを選ぶ Lesson 5, 10, 12
    3. パートを組む 各 live_loop を作る Lesson 12, 14
    4. 同期を設定する sync / cue でタイミングを揃える Lesson 14
    5. 展開を実践する 台本に沿って演奏する Lesson 14

    進め方¶

    ステップ 1: 構成を設計する

    完全な即興ではなく、展開の台本を先に作ります。Lesson 14.5 で学んだ「導入→構築→展開→ブレイク→終結」の流れを参考に、どのタイミングで何をするかを決めましょう。

    台本の例（2〜3 分の構成）:

    時間 フェーズ 操作
    0:00 導入 ハイハットだけでスタート
    0:15 構築 キック追加、ベースの amp を上げる
    0:45 展開 メロディ追加、スネアにリバーブ
    1:15 変化 スケールをマイナーに変更
    1:45 ブレイク キック以外をミュート
    2:00 再構築 全パート復帰、エコー追加
    2:30 終結 パートを1つずつ減らす

    ステップ 2〜4: コードを用意する

    Lesson 14.6 で紹介したテンプレート方式が便利です。すべてのパートを amp: 0 で用意しておき、台本に沿って値を変えていきます。

    use_bpm 120

live_loop :metro do
  cue :beat
  sleep 1
end

live_loop :kick do
  sync :beat
  sample :bd_haus, amp: 0    # ← 台本に合わせて 0→1 に変える
  sleep 1
end

live_loop :snare do
  sync :beat
  sleep 1
  sample :sn_dub, amp: 0
  sleep 1
end

live_loop :hihat do
  sync :beat
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

live_loop :bass do
  sync :beat
  use_synth :tb303
  play :e2, release: 0.3, cutoff: 80, amp: 0
  sleep 0.5
end

live_loop :melody do
  sync :beat
  use_synth :prophet
  play (scale :e4, :minor_pentatonic).choose, release: 0.3, amp: 0
  sleep (ring 0.5, 0.5, 1).tick
end

    ステップ 5: リハーサルする

    台本を見ながら実際に演奏してみましょう。コードのどこを変えるかを事前に確認しておくと、本番でスムーズに操作できます。

    提出物の目安¶

    • Sonic Pi のコード（初期状態のテンプレート）
    • 展開の台本（上の表のような形式）
    • 演奏の振り返り（100〜200 字程度）: うまくいった点、難しかった点

    15.4 制作のヒント¶

    どのテーマを選んでも、以下のことを意識すると作品がまとまりやすくなります。

    小さく始める¶

    最初から壮大なものを目指さず、まず動く最小限のものを作りましょう。メロディ 4 小節だけ、エフェクト 1 種類だけ、ループ 2 つだけ——それで十分です。動くものができたら、少しずつ広げていきます。

    こまめに聴く¶

    コードを長々と書いてから初めて実行すると、どこに問題があるかわかりません。数行書いたら実行して音を聴く、を繰り返しましょう。

    「なぜ」を意識する¶

    パラメータをただ試行錯誤するのではなく、「なぜこの値にするとこう聞こえるのか」を考えてみてください。Lesson 1〜13 で学んだ原理が、その答えを与えてくれるはずです。

    15.5 発表¶

    作品が完成したら、発表しましょう。発表は作品を磨く最後のステップです。

    発表の形式¶

    形式 内容 時間の目安
    Python コース 画面を共有しながらコードと結果を説明 3〜5 分
    Sonic Pi コース（テーマ C） コードを見せながら演奏を再生 3〜5 分
    Sonic Pi コース（テーマ D） ライブコーディングの実演 2〜3 分 + 説明 1 分

    発表で伝えること¶

    • 何を作ったか: テーマと概要を簡潔に
    • 工夫した点: どこに力を入れたか、どのレッスンの知識を使ったか
    • 発見や気づき: 作ってみて初めてわかったこと

    フィードバックの視点¶

    他の人の発表を聴くときは、以下の視点でコメントしてみましょう。

    • 面白いと思った点、真似したいと思った点
    • 「こうするともっと良くなりそう」というアイデア
    • 自分の作品との違いから得た気づき
