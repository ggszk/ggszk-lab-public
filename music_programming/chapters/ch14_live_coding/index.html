    Lesson 14: ライブコーディング技法¶

    このレッスンで学ぶこと¶

    • ライブコーディングの考え方とパフォーマンスの基礎を理解する
    • live_loop の同期（sync / cue）を習得する
    • set / get を使ってループ間で値を共有する方法を学ぶ
    • リアルタイムに音楽を変化させるテクニックを身につける
    • これまでのレッスンの知識を統合してライブパフォーマンスを構成する

    Lesson 12 では live_loop を使ってリズムパターンを組み立て、「コードを変えて Run を押すだけでパターンが切り替わる」というライブコーディングの醍醐味に触れました。このレッスンでは、そのテクニックをさらに掘り下げ、複数のループを正確に同期させたり、演奏中に構成を展開させたりする方法を学びます。

    14.1 ライブコーディングとは¶

    ライブコーディング（live coding）は、プログラムを書きながらリアルタイムに音楽や映像を生成するパフォーマンスの手法です。あらかじめ完成した曲を再生するのではなく、観客の前でコードを書き、修正しながら音楽を作り上げていきます。

    Sonic Pi はライブコーディングのために設計されたツールで、以下の特徴を持っています。

    特徴 説明
    ホットリロード コードを変えて「Run」を押すと、演奏を止めずにループが更新される
    タイミング保証 sleep の時間が正確に管理され、リズムがずれない
    エラー耐性 コードにエラーがあっても、前のループが動き続ける

    これまでのレッスンで学んだ play、sample、use_synth、with_fx、live_loop などを組み合わせて、即興的な音楽パフォーマンスができます。

    14.2 live_loop の同期 — sync と cue¶

    Lesson 12 では複数の live_loop を同時に動かしましたが、それぞれのループは独立に開始されるため、タイミングがずれることがあります。特にコードを変更して「Run」を押し直したとき、ループの開始タイミングがばらばらになりがちです。

    問題を確認する¶

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :snare do
  sleep 1
  sample :sn_dub
  sleep 1
end

    このコードを何度か「Run」し直すと、キックとスネアのタイミングがずれることがあります。

    sync で解決する¶

    sync を使うと、あるループが別のループのタイミングに合わせて動き始めます。

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :snare do
  sync :kick
  sample :sn_dub
  sleep 1
end

    :snare ループは sync :kick によって :kick ループの先頭に同期します。何度「Run」を押しても、スネアはキックに合わせて再開します。

    cue で明示的に合図を送る¶

    sync はループ名を指定しますが、cue を使うと明示的に合図（キュー）を送ることができます。

    use_bpm 120

live_loop :metronome do
  cue :tick
  sleep 1
end

live_loop :kick do
  sync :tick
  sample :bd_haus
end

live_loop :hihat do
  sync :tick
  sample :hat_snap, amp: 0.5
end

    :metronome ループが毎拍 cue :tick を送り、他のループがそれに同期します。メトロノームが全体の「指揮者」の役割を果たします。

    方法 動作 用途
    sync :ループ名 指定したループの先頭まで待つ 2つのループを同期
    cue :名前 名前付きの合図を送る 複数ループの同期点を統一
    sync :名前 cue の合図を待つ cue と対で使う

    14.3 set / get — ループ間で値を共有する¶

    ライブコーディングでは、演奏中にテンポやパターンを変えたいことがよくあります。set と get を使うと、ループ間で値を共有できます。

    基本的な使い方¶

    set :my_note, :e3

live_loop :bass do
  use_synth :tb303
  play get[:my_note], release: 0.3, cutoff: 80
  sleep 0.5
end

    このコードを実行した後、バッファの先頭で set :my_note, :a3 に変えて「Run」を押すと、ベースの音が変わります。ループのコード自体は変更せず、共有された値だけを変えています。

    パターンの切り替え¶

    use_bpm 120

set :kick_pattern, (ring 1, 0, 0, 0, 1, 0, 0, 0)

live_loop :kick do
  sample :bd_haus if get[:kick_pattern].tick == 1
  sleep 0.5
end

live_loop :hihat do
  sample :hat_snap, amp: 0.5
  sleep 0.5
end

    演奏中に set :kick_pattern, (ring 1, 0, 1, 0, 1, 0, 1, 0) に変えて「Run」を押すと、キックが四つ打ちに切り替わります。ハイハットのループには一切触れずに済みます。

    複数の値を制御する¶

    use_bpm 120

# 制御パラメータ
set :kick_pattern, (ring 1, 0, 0, 0, 1, 0, 0, 0)
set :snare_pattern, (ring 0, 0, 1, 0, 0, 0, 1, 0)
set :hat_amp, 0.5
set :fx_mix, 0.0

live_loop :metro do
  cue :beat
  sleep 0.5
end

live_loop :kick do
  sync :beat
  sample :bd_haus if get[:kick_pattern].tick == 1
end

live_loop :snare do
  sync :beat
  with_fx :reverb, mix: get[:fx_mix] do
    sample :sn_dub if get[:snare_pattern].tick == 1
  end
end

live_loop :hihat do
  sync :beat
  sample :hat_snap, amp: get[:hat_amp]
end

    パラメータをまとめて上部に並べることで、演奏中に変更したい部分が一目でわかります。set の行だけを書き換えて「Run」を押せば、各ループに即座に反映されます。

    14.4 リアルタイム変更のテクニック¶

    ライブコーディングでは「何を変えるか」だけでなく「どう変えるか」も重要です。ここでは、演奏中に使える実践的なテクニックを紹介します。

    テクニック1: ミュートとソロ¶

    特定のループを一時的にミュート（消音）するには、音量をゼロにするのが簡単です。

    use_bpm 120

live_loop :kick do
  sample :bd_haus, amp: 1  # ← 0 にするとミュート
  sleep 1
end

live_loop :snare do
  sleep 1
  sample :sn_dub, amp: 1   # ← 0 にするとミュート
  sleep 1
end

live_loop :hihat do
  sample :hat_snap, amp: 0.5
  sleep 0.5
end

    amp: 1 を amp: 0 に変えて「Run」を押すだけでミュートできます。元に戻すのも簡単です。

    テクニック2: 段階的にエフェクトを加える¶

    use_bpm 120

live_loop :melody do
  use_synth :prophet
  with_fx :reverb, mix: 0.3 do       # ← mix を増やすと深いリバーブに
    with_fx :echo, phase: 0.75, mix: 0.0 do  # ← mix を 0→0.3 で徐々にエコーを加える
      play (scale :e3, :minor_pentatonic).choose, release: 0.3, cutoff: 90
      sleep 0.5
    end
  end
end

    エフェクトの mix: を 0.0 から徐々に上げていくと、音が自然に変化していきます。

    テクニック3: スケールやコードを切り替える¶

    use_bpm 120

live_loop :melody do
  use_synth :piano
  notes = (scale :c4, :major)      # ← :minor に変えると雰囲気が変わる
  play notes.choose, amp: 0.8
  sleep 0.5
end

live_loop :bass do
  use_synth :tb303
  play :c2, release: 0.3, cutoff: 70  # ← :a2 に変えるとマイナー感
  sleep 1
end

    スケールを :major から :minor に変え、ベースの音を :c2 から :a2 に変えるだけで、曲の雰囲気ががらりと変わります。Lesson 7 で学んだスケールとコードの知識がここで活きてきます。

    テクニック4: 新しいループを追加する¶

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

# ↓ 演奏中にこのブロックを追加して Run
live_loop :bass do
  use_synth :tb303
  play :e2, release: 0.3, cutoff: 80
  sleep 0.5
end

    演奏中に新しい live_loop を追加して「Run」を押すと、既存のループを止めずに新しいパートが加わります。逆に、ループの中身を sleep 1 だけにすれば、そのパートを無音にできます。

    # パートを無音にする
live_loop :bass do
  sleep 1
end

    14.5 構成を展開する — 曲としてのライブコーディング¶

    ただループを鳴らし続けるだけでは、曲としての起承転結がありません。ライブコーディングでも、構成（ストラクチャー）を意識することが大切です。

    展開の基本パターン¶

    フェーズ 内容 テクニック
    導入（Intro） 1〜2パートから始める キックだけ、またはメロディだけ
    構築（Build） パートを徐々に追加 ループの追加、amp を上げる
    展開（Drop / Main） 全パートが揃った状態 エフェクトやパターン変更で変化をつける
    ブレイク（Break） 一部のパートを抜く ミュートやフィルター
    再構築 再びパートを戻す ミュート解除、新しい要素の追加
    終結（Outro） パートを徐々に減らす amp を下げる、ループを無音化

    実践: 4段階の展開¶

    以下のコードを出発点として、段階的に展開させてみましょう。

    フェーズ1: 導入（キックだけ）

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

    フェーズ2: ハイハットを追加

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

    フェーズ3: ベースとスネアを追加

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

live_loop :snare do
  sleep 1
  sample :sn_dub
  sleep 1
end

live_loop :bass do
  use_synth :tb303
  play (ring :e2, :e2, :g2, :a2).tick, release: 0.3, cutoff: 80
  sleep 0.5
end

    フェーズ4: メロディとエフェクトを追加

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

live_loop :snare do
  sleep 1
  with_fx :reverb, mix: 0.3 do
    sample :sn_dub
  end
  sleep 1
end

live_loop :bass do
  use_synth :tb303
  play (ring :e2, :e2, :g2, :a2).tick, release: 0.3, cutoff: 80
  sleep 0.5
end

live_loop :melody do
  use_synth :prophet
  with_fx :echo, phase: 0.75, mix: 0.2 do
    play (scale :e4, :minor_pentatonic).choose, release: 0.3, amp: 0.6, cutoff: 90
    sleep (ring 0.5, 0.5, 1, 0.25, 0.25).tick
  end
end

    各フェーズでコードを書き換えて「Run」を押します。前のフェーズのループが鳴り続けた状態で新しいパートが加わるため、途切れのない展開になります。

    14.6 ライブパフォーマンスのコツ¶

    実際にライブコーディングパフォーマンスをするとき、いくつか知っておくと役立つことがあります。

    コードの準備¶

    完全な即興もできますが、最初はテンプレートを用意しておくのが安全です。

    # === テンプレート ===
use_bpm 120

# --- リズム ---
live_loop :kick do
  sample :bd_haus, amp: 1
  sleep 1
end

live_loop :snare do
  sleep 1
  sample :sn_dub, amp: 0
  sleep 1
end

live_loop :hihat do
  sample :hat_snap, amp: 0
  sleep 0.5
end

# --- ベース ---
live_loop :bass do
  use_synth :tb303
  play :e2, release: 0.3, cutoff: 80, amp: 0
  sleep 0.5
end

# --- メロディ ---
live_loop :melody do
  use_synth :prophet
  play :e4, release: 0.3, cutoff: 90, amp: 0
  sleep 0.5
end

    すべてのパートを amp: 0 で用意しておき、演奏中に amp: の値を変えて「Run」を押すことでパートを出し入れします。

    Stop ボタンの使い方¶

    Sonic Pi の「Stop」ボタンを押すと、すべてのループが停止します。意図しないエラーで音が止まらなくなった場合の緊急停止に使います。

    よくあるトラブルと対処¶

    トラブル 原因 対処
    ループがずれる sync を使っていない メトロノームループ + sync で統一
    音が重なって大きくなる パートの追加で音量が増加 個々の amp: を控えめに設定
    変更が反映されない ループ名を変えてしまった 元のループ名を維持する（名前が違うと新しいループが作られる）
    エラーで音が止まる 文法エラー Stop → 修正 → Run

    このレッスンのライブコーディングには、これまでに学んだ多くの知識が活きています。

    レッスン 活用する知識
    Lesson 3 play、sleep、use_synth の基本操作
    Lesson 5 cutoff でフィルターを制御し、音色をリアルタイムに変える
    Lesson 7 scale、chord でメロディやハーモニーを構成する
    Lesson 10 ADSR エンベロープと with_fx で音に表情をつける
    Lesson 12 live_loop、sample、ring、tick でリズムを組む

    Python 回で学んだ理論——波形（Lesson 1-2）、倍音（Lesson 4）、音階（Lesson 6）、エンベロープ（Lesson 8）、エフェクト（Lesson 9）、リズム（Lesson 11）、スペクトル（Lesson 13）——が、Sonic Pi でのパフォーマンスの土台になっています。「なぜこの cutoff の値で音が変わるのか」「なぜ :minor_pentatonic がこの雰囲気になるのか」を理解しているからこそ、意図を持った演奏ができるのです。

    まとめ¶

    このレッスンで学んだことを整理します。

    コマンド / 概念 役割 例
    sync 他のループやキューに同期して待つ sync :kick
    cue 名前付きの合図を送る cue :beat
    set 値をグローバルに設定する set :note, :e3
    get set で設定した値を取り出す get[:note]
    ミュート amp: 0 でパートを無音にする sample :bd_haus, amp: 0
    パートの追加 新しい live_loop を追加して Run 演奏中に新パートを挿入
    概念 内容
    ライブコーディング コードを書きながらリアルタイムに音楽を生成するパフォーマンス手法
    ループの同期 sync / cue でループのタイミングを揃える
    値の共有 set / get でループ間でパラメータを共有し、演奏中に変更
    構成の展開 導入→構築→展開→ブレイク→終結の流れで曲を組み立てる

    Lesson 12 との対応¶

    Lesson 12 Lesson 14
    live_loop でリズムを繰り返す live_loop + sync で正確に同期
    リングでパターンを定義 set / get で演奏中にパターンを切り替え
    「Run」でパターン変更 ミュート・追加・エフェクトで構成を展開
    1パターンの繰り返し 曲全体の構成を意識した展開
