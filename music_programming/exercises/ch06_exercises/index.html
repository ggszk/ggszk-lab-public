    Lesson 6 演習問題¶

    演習1: MIDI 番号と周波数の変換¶

    以下の MIDI 番号の周波数を、変換式 \(f = 440 \times 2^{(n-69)/12}\) を使って手計算で求めなさい（電卓可）。その後、Python で検算すること。

    1. MIDI 69（A4）
    2. MIDI 81（A5）
    3. MIDI 60（C4）
    4. MIDI 57（A3）

    ヒント: MIDI 69 を基準にすると、69 からの差が 12 の倍数のときは \(2^{(n-69)/12}\) が整数乗になり計算しやすい。

    演習2: ドレミファソラシドを別の音色で鳴らす¶

    本文では sine_wave() でドレミファソラシドを鳴らしました。次の課題に取り組みなさい。

    1. sine_wave() の代わりに sawtooth_wave() を使って同じスケールを鳴らす
    2. サイン波とノコギリ波の聞こえ方の違いを、Lesson 4 の倍音理論を使って説明する
    3. C4 からではなく、A3（MIDI 57）から始まる A マイナースケール（ラシドレミファソラ）を鳴らす

    ヒント: A マイナースケールの半音間隔は「全半全全半全全」（C メジャーと同じ音を使うが、ラから始まる）。MIDI 番号で表すと 57, 59, 60, 62, 64, 65, 67, 69。

    演習3: 音程を聞き比べる¶

    A4（440 Hz）を基準音として、以下の音程を2音同時に鳴らし、響きの印象を記述しなさい。

    1. 完全5度（A4 + E5）
    2. 長3度（A4 + C#5）
    3. 短3度（A4 + C5）
    4. オクターブ（A4 + A5）

    2音同時に鳴らすには、2つのサイン波の NumPy 配列を足し合わせます。

    sig1 = sine_wave(440, 2.0)
sig2 = sine_wave(660, 2.0)  # 完全5度
mixed = AudioSignal((sig1.data + sig2.data) / 2, 44100)

    演習4: 平均律と純正律の聞き比べ¶

    以下の手順で、平均律と純正律の長3度の違いを体験しなさい。

    1. A4（440 Hz）と平均律の C#5（\(440 \times 2^{4/12}\) Hz）を同時に鳴らす
    2. A4（440 Hz）と純正律の C#5（\(440 \times 5/4\) Hz）を同時に鳴らす
    3. 2つの和音を交互に聞き比べ、違いを記述する
    4. 周波数の差（Hz）を求める

    ヒント: 純正律のほうが「澄んでいる」「うなりが少ない」と感じる人が多い。サイン波よりもノコギリ波（倍音が豊富）で聞き比べると差がわかりやすい。

    演習5: 周波数比のグラフを作る¶

    以下のグラフを作成しなさい。

    1. 横軸を MIDI ノート番号（21〜108）、縦軸を周波数（Hz）とした線形スケールのグラフ
    2. 同じデータを対数スケール（plt.semilogy()）で描いたグラフ
    3. 2つのグラフを plt.subplots(2, 1) で縦に並べて表示する
    4. 各オクターブの A の位置（MIDI 21, 33, 45, 57, 69, 81, 93, 105）に縦線を引く（plt.axvline()）

    演習6（発展）: 他の音律を作ってみる¶

    平均律以外の音律を Python で実装し、聞き比べなさい。

    1. ピタゴラス音律: 完全5度（周波数比 3:2）を繰り返し積み重ねてスケールを作る
    2. C → G（×3/2）→ D（×3/2、オクターブ下に戻す）→ A → E → B → F# → …
    3. 12回の5度圏でオクターブに戻るはずだが、\((3/2)^{12} \neq 2^7\) のため微妙にずれる（ピタゴラスコンマ）
    4. ピタゴラスコンマの周波数比を求める
    5. ピタゴラス音律と平均律の C メジャースケールを聞き比べる

    ヒント: ピタゴラスコンマ = \(\frac{3^{12}}{2^{19}} \approx 1.01364\)（約 1.4% のずれ）
