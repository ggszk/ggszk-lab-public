    Lesson 12 演習解答¶

    演習1: サンプルを試す¶

    # キック系
sample :bd_haus
sleep 1
sample :bd_boom
sleep 1
sample :bd_klub
sleep 2

# スネア系
sample :sn_dub
sleep 1
sample :sn_dolf
sleep 1
sample :sn_generic
sleep 2

# ハイハット系
sample :hat_snap
sleep 1
sample :hat_cab
sleep 2

# rate の変化
sample :bd_haus, rate: 0.5
sleep 2
sample :bd_haus, rate: 1.0
sleep 1
sample :bd_haus, rate: 2.0

    解説: rate: 0.5 では再生速度が半分になり、音が低く長くなります。rate: 2.0 では倍速になり、音が高く短くなります。これは Lesson 1 で学んだサンプリングレートの原理と同じで、再生速度と音高は比例します。

    演習2: 四つ打ちパターンを作る¶

    use_bpm 128

# キック: 4分音符ごと
live_loop :kick do
  sample :bd_haus
  sleep 1
end

# ハイハット: 8分音符ごと
live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

# スネア: 2拍目と4拍目
live_loop :snare do
  sample :sn_dub if (ring 0, 1, 0, 1).tick == 1
  sleep 1
end

    解説: 四つ打ちはキックが毎拍鳴るパターンで、ハウスやテクノの基本です。キックは sleep 1 だけで済むのでリングが不要です。スネアの (ring 0, 1, 0, 1) は「1拍目=休み、2拍目=鳴る、3拍目=休み、4拍目=鳴る」を表しています。3つの live_loop が独立に動いていることがポイントです。

    演習3: spread を試す¶

    use_bpm 120

# --- パターン1: spread(2, 8) ---
live_loop :kick do
  sample :bd_haus if (spread 2, 8).tick
  sleep 0.5
end

live_loop :snare do
  sample :sn_dub if (ring 0, 0, 1, 0, 0, 0, 1, 0).tick == 1
  sleep 0.5
end

live_loop :hihat do
  sample :hat_snap, amp: 0.5
  sleep 0.5
end

    パターンを切り替えるには、:kick のループ内の spread を変更して「Run」を押します。

    # パターン2: spread(4, 8)
live_loop :kick do
  sample :bd_haus if (spread 4, 8).tick
  sleep 0.5
end

# パターン3: spread(5, 8)
live_loop :kick do
  sample :bd_haus if (spread 5, 8).tick
  sleep 0.5
end

    解説: - spread(2, 8): 8ステップに2打だけなので、キックがまばらでゆったりした印象です。レゲエやダブのようなスカスカしたリズムになります - spread(4, 8): 8ステップに4打で、四つ打ちに相当します。安定した推進力のあるリズムです - spread(5, 8): 8ステップに5打で、裏拍にもキックが入ります。少し複雑で、ラテン音楽やアフリカ音楽を思わせるリズムになります

    演習4: アクセント付きハイハット¶

    use_bpm 120

# シャッフル風ハイハット（3連符単位）
live_loop :hihat_shuffle do
  # 3連符の1つ目(強), 2つ目(休み), 3つ目(弱) を繰り返す
  amps = (ring 0.7, 0, 0.3)
  a = amps.tick
  sample :hat_snap, amp: a if a > 0
  sleep 1.0 / 3
end

# キック: 1拍目と3拍目
live_loop :kick do
  sample :bd_haus if (ring 1, 0, 1, 0).tick == 1
  sleep 1
end

# スネア: 2拍目と4拍目
live_loop :snare do
  sample :sn_dub if (ring 0, 1, 0, 1).tick == 1
  sleep 1
end

    解説: 3連符の2つ目を抜く（1つ目と3つ目だけ鳴らす）とシャッフル（スウィング）のリズムになります。amp: のリングで 0.7, 0, 0.3 と設定し、2つ目は a > 0 の条件で鳴らさないようにしています。1つ目を強く、3つ目を弱くすることで、跳ねるようなグルーヴ感が生まれます。

    演習5: FX 付きドラムパターン¶

    use_bpm 120

# 全体をコンプレッサーで包む
with_fx :compressor, threshold: 0.3, slope_above: 0.5 do

  # キック（FX なし）
  live_loop :kick do
    sample :bd_haus if (ring 1, 0, 0, 0, 1, 0, 0, 0).tick == 1
    sleep 0.5
  end

  # スネア + リバーブ
  live_loop :snare do
    with_fx :reverb, room: 0.7, mix: 0.4 do
      sample :sn_dub if (ring 0, 0, 1, 0, 0, 0, 1, 0).tick == 1
    end
    sleep 0.5
  end

  # ハイハット + ハイパスフィルター
  live_loop :hihat do
    with_fx :hpf, cutoff: 100 do
      sample :hat_snap, amp: 0.5
    end
    sleep 0.5
  end

end

    解説: エフェクトの適用順序は内側から外側です。スネアにはリバーブで空間的な広がりを、ハイハットには :hpf（ハイパスフィルター）で低域をカットしてシャープな音にしています。全体を :compressor で包むことで、キックの強い音とハイハットの弱い音の音量差を縮め、全体のまとまりが良くなります。Lesson 9 で学んだコンプレッサーの「大きい音を抑え、小さい音を相対的に持ち上げる」効果です。

    演習6（発展）: オリジナルリズムパターン¶

    # ラテン風リズム（BPM 105）
# ユークリッドリズムを使って、ラテン音楽特有の複雑なパターンを表現
use_bpm 105

with_fx :compressor, threshold: 0.4 do

  # キック: ユークリッドリズム spread(3, 8)
  live_loop :kick do
    sample :bd_boom, amp: 0.9 if (spread 3, 8).tick
    sleep 0.5
  end

  # スネア（リムショット風）: 2拍目と4拍目
  live_loop :snare do
    with_fx :reverb, room: 0.4, mix: 0.3 do
      sample :sn_dolf, amp: 0.7 if (ring 0, 0, 1, 0, 0, 0, 1, 0).tick == 1
    end
    sleep 0.5
  end

  # ハイハット: アクセント付き
  live_loop :hihat do
    amps = (ring 0.6, 0.2, 0.4, 0.2, 0.6, 0.2, 0.4, 0.2)
    sample :hat_cab, amp: amps.tick
    sleep 0.5
  end

  # シェイカー（追加パーカッション）: 16分音符で細かく刻む
  live_loop :shaker do
    amps = (ring 0.3, 0.1, 0.2, 0.1)
    sample :perc_snap, amp: amps.tick, rate: 1.5
    sleep 0.25
  end

  # カウベル: ユークリッドリズム spread(5, 16)
  live_loop :cowbell do
    with_fx :echo, phase: 0.5, decay: 1, mix: 0.15 do
      sample :elec_blip, amp: 0.3, rate: 2.0 if (spread 5, 16).tick
    end
    sleep 0.25
  end

end

    解説: BPM 105 のラテン風リズムです。キックに spread(3, 8)、カウベルに spread(5, 16) のユークリッドリズムを使い、均等に分散された打点でラテンらしい複雑さを出しています。ハイハットとシェイカーにはそれぞれ amp: のリングでアクセントをつけ、人間が演奏しているようなニュアンスを加えています。カウベルには軽いエコーをかけて空間的な奥行きを与え、全体をコンプレッサーでまとめています。
