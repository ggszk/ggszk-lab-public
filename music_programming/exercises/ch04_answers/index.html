    Lesson 4 演習解答¶

    演習1: 解答例¶

    from audio_lib import sine_wave
from audio_lib.notebook import play_sound
from IPython.display import display

f0 = 220
dur = 1.5

for k in range(1, 9):
    freq = f0 * k
    display(play_sound(sine_wave(freq, dur), f"第{k}倍音: {freq}Hz"))

    1. 各倍音の周波数:

    倍音 周波数
    第1（基本波） 220 Hz
    第2 440 Hz
    第3 660 Hz
    第4 880 Hz
    第5 1100 Hz
    第6 1320 Hz
    第7 1540 Hz
    第8 1760 Hz

    2. 音程関係:

    倍音 音程関係
    第2 1オクターブ上
    第3 1オクターブ+完全5度上
    第4 2オクターブ上
    第5 2オクターブ+長3度上
    第6 2オクターブ+完全5度上
    第7 （既存の音階に正確には当てはまらない）
    第8 3オクターブ上

    3. 第7倍音について: 第7倍音（1540Hz）は平均律のシ♭（約1480Hz）とシ（約1568Hz）の間に位置し、やや低めのシ♭に近い。自然倍音列の音程は平均律とは一致せず、これが「純正律」と「平均律」の違いの出発点でもある。

    演習2: 解答例¶

    from audio_lib import additive_synth
from audio_lib.notebook import play_sound, plot_harmonics
from IPython.display import display

# 柔らかい音: 基本波が支配的
soft = {1: 1.0, 2: 0.1, 3: 0.02}
sig_soft = additive_synth(440, soft)
display(play_sound(sig_soft, "柔らかい音"))
plot_harmonics(sig_soft, max_freq=5000, title="柔らかい音")

# 明るい音: 多くの倍音を含む
bright = {k: 1.0/k for k in range(1, 16)}
sig_bright = additive_synth(440, bright)
display(play_sound(sig_bright, "明るい音"))
plot_harmonics(sig_bright, max_freq=8000, title="明るい音")

# 中空な音: 基本波が弱い
hollow = {1: 0.2, 2: 1.0, 3: 0.8, 4: 0.6}
sig_hollow = additive_synth(440, hollow)
display(play_sound(sig_hollow, "中空な音"))
plot_harmonics(sig_hollow, max_freq=5000, title="中空な音")
    • 柔らかい音: 高次倍音がほとんどないため、サイン波に近い丸い音色。フルートの低音域に似た印象
    • 明るい音: 多くの倍音が含まれるためノコギリ波的。ブラスやストリングスのような存在感がある
    • 中空な音: 基本波が弱く倍音が強いため、音の高さが曖昧で木管楽器のような独特の響き。オクターブ上の成分が強いため「高い音」に聞こえやすい

    演習3: 解答例¶

    import numpy as np
import matplotlib.pyplot as plt
from audio_lib import AudioSignal
from audio_lib.notebook import play_sound
from IPython.display import display

sample_rate = 44100
f0 = 440
dur = 2.0
t = np.linspace(0, dur, int(sample_rate * dur), endpoint=False)

show_samples = int(sample_rate * 2 / f0)
t_show = t[:show_samples] * 1000

N_list = [1, 3, 5, 10, 20]

fig, axes = plt.subplots(len(N_list), 1, figsize=(12, 10), sharex=True)

for ax, N in zip(axes, N_list):
    data = np.zeros_like(t)
    for i, k in enumerate(range(1, N * 2, 2)):  # 奇数次: 1, 3, 5, ...
        sign = (-1.0) ** i
        data += sign * np.sin(2 * np.pi * k * f0 * t) / k ** 2
    data *= 8.0 / np.pi ** 2

    ax.plot(t_show, data[:show_samples])
    ax.set_ylabel(f"N={N}")
    ax.set_ylim(-1.3, 1.3)
    ax.grid(True, alpha=0.3)

    sig = AudioSignal(data, sample_rate)
    display(play_sound(sig, f"三角波 N={N}"))

axes[-1].set_xlabel("時間 (ms)")
fig.suptitle("三角波: 倍音の数による変化", fontsize=14)
plt.tight_layout()
plt.show()

    2. 少ない倍音で完成に近づく理由: 三角波の倍音は \(1/k^2\) で減衰するのに対し、矩形波は \(1/k\) で減衰する。例えば第5倍音の振幅は、矩形波では \(1/5 = 0.2\)（基本波の20%）だが、三角波では \(1/25 = 0.04\)（基本波の4%）しかない。高次倍音の寄与が非常に小さいため、少数の倍音でほぼ完全な波形が得られる。

    3. ギブス現象について: 三角波にはギブス現象が起きない。三角波は連続な波形であり、値そのものに不連続点がないためである。矩形波やノコギリ波のように値が急に跳ぶ箇所でのみギブス現象が発生する。

    演習4: 解答例¶

    from audio_lib import additive_synth
from audio_lib.notebook import play_sound, plot_spectrum
from IPython.display import display

# 音A: 整数倍の倍音
recipe_a = {1: 1.0, 2: 0.5, 3: 0.3, 4: 0.2, 5: 0.1}
sig_a = additive_synth(440, recipe_a)
display(play_sound(sig_a, "音A（整数倍）"))
plot_spectrum(sig_a, max_freq=4000, title="音A（整数倍）")

# 音B: 非整数倍を含む
recipe_b = {1: 1.0, 2.1: 0.5, 3.3: 0.3, 4.7: 0.2, 5.9: 0.1}
sig_b = additive_synth(440, recipe_b)
display(play_sound(sig_b, "音B（非整数倍）"))
plot_spectrum(sig_b, max_freq=4000, title="音B（非整数倍）")

# さらに非整数比を大きくする
recipe_c = {1: 1.0, 2.5: 0.5, 3.7: 0.3, 5.3: 0.2, 7.1: 0.1}
sig_c = additive_synth(440, recipe_c)
display(play_sound(sig_c, "音C（非整数倍・大）"))

    1. 聞こえ方の違い: 音A は明確な音程感があり「楽器的」に聞こえる。音B は音程は聞き取れるものの、わずかに濁りや「うねり」が加わり、金属的な響きを帯びる。

    2. 非整数比を大きくした場合: 周波数比が整数からさらに離れると、音程感が曖昧になり、鐘・シンバル・ゴングのような打楽器的な響きになる。極端に離すと「音階のある音」というより「音響」に近くなる。

    3. 打楽器との関係: 太鼓・シンバルなどの打楽器は膜や板の振動モードが整数比にならないため、非調和倍音を多く含む。これが打楽器が「音程感の薄い音」に聞こえる理由であり、逆にティンパニやマリンバは倍音が比較的整数比に近いため音程を持つ。

    演習5: 解答例¶

    from audio_lib import additive_synth
from audio_lib.notebook import play_sound, plot_harmonics
from IPython.display import display

# 例: 「木霊（こだま）」— 奇数次倍音主体だが第6倍音も加えた不思議な音色
kodama_recipe = {
    1: 1.0,
    3: 0.6,
    5: 0.35,
    6: 0.2,
    7: 0.15,
    9: 0.08,
}

for freq in [220, 440, 880]:
    sig = additive_synth(freq, kodama_recipe)
    display(play_sound(sig, f"木霊 {freq}Hz"))

plot_harmonics(additive_synth(440, kodama_recipe), max_freq=6000, title="「木霊」の倍音構成")

    音域による違い: - 220Hz: 倍音が豊富で太い音。低音域では倍音が人間の聴覚の感度が高い範囲（1000〜4000Hz）に入るため、音色の特徴がよく聞こえる - 440Hz: 基本波がはっきり聞こえ、バランスの良い音 - 880Hz: 高次倍音が可聴域の上限に近づくため、やや単調でサイン波に近い印象になる

    レシピの微調整は試行錯誤で行う。例えば第3倍音の振幅を 0.6 → 0.4 に下げると柔らかくなり、0.8 に上げると矩形波的な硬さが増す。
