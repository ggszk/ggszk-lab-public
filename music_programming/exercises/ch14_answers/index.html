    Lesson 14 演習解答¶

    演習1: sync で同期する¶

    :snare ループの先頭に sync :kick を追加します。

    use_bpm 120

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :snare do
  sync :kick        # ← 追加: キックに同期
  sleep 1
  sample :sn_dub
  sleep 1
end

    sync :kick によって、スネアのループは毎回キックのループの先頭タイミングに合わせて再開します。何度「Run」を押しても、2つのループがずれることがありません。

    演習2: set / get でパターンを切り替える¶

    set でパターンを定義し、live_loop 内で get を使って読み取ります。

    use_bpm 120

# ↓ ここを変えて Run を押すだけでパターンが切り替わる
set :kick_pattern, (ring 1, 0, 0, 0, 1, 0, 0, 0)

live_loop :kick do
  sample :bd_haus if get[:kick_pattern].tick == 1
  sleep 0.5
end

live_loop :hihat do
  sample :hat_snap, amp: 0.5
  sleep 0.5
end

    四つ打ちに切り替えるときは、先頭の set を以下に変更して「Run」を押します。

    set :kick_pattern, (ring 1, 0, 1, 0, 1, 0, 1, 0)

    演習3: ミュートの仕組み¶

    方法1: amp を 0 にする

    live_loop :bass do
  use_synth :tb303
  play :e2, release: 0.3, cutoff: 80, amp: 0  # ← amp: 0 でミュート
  sleep 0.5
end

    方法2: ループの中身を sleep だけにする

    live_loop :bass do
  sleep 0.5  # ← 音を鳴らさず sleep だけにする
end

    どちらでもミュートできますが、方法1の方が元に戻しやすい（amp: 0 を amp: 1 に変えるだけ）ため、ライブコーディングでは方法1がよく使われます。方法2はベースのシンセや音色の設定を消してしまうので、復帰時に再入力が必要です。

    演習4: メトロノーム方式の同期¶

    use_bpm 110

# メトロノーム（指揮者）
live_loop :metro do
  cue :beat
  sleep 0.5
end

# キック: 1拍目と3拍目
live_loop :kick do
  sync :beat
  sample :bd_haus if (ring 1, 0, 0, 0, 1, 0, 0, 0).tick == 1
end

# スネア: 2拍目と4拍目
live_loop :snare do
  sync :beat
  sample :sn_dub if (ring 0, 0, 1, 0, 0, 0, 1, 0).tick == 1
end

# ハイハット: 全ステップ（強弱あり）
live_loop :hihat do
  sync :beat
  amps = (ring 0.7, 0.3, 0.5, 0.3, 0.7, 0.3, 0.5, 0.3)
  sample :hat_snap, amp: amps.tick
end

    :metro ループが cue :beat を 8分音符ごとに送り、すべてのパートがそれに sync しています。テンポを変えたいときは use_bpm の値を変えるだけで全パートに反映されます。

    演習5: 段階的な展開¶

    フェーズ1: 導入（ハイハットだけ）

    use_bpm 120

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

    フェーズ2: キックとスネアを追加

    use_bpm 120

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :snare do
  sleep 1
  sample :sn_dub
  sleep 1
end

    フェーズ3: ベースとメロディを追加、スネアにリバーブ

    use_bpm 120

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :snare do
  sleep 1
  with_fx :reverb, mix: 0.4 do
    sample :sn_dub
  end
  sleep 1
end

live_loop :bass do
  use_synth :tb303
  play (ring :c2, :c2, :eb2, :f2).tick, release: 0.3, cutoff: 80
  sleep 0.5
end

live_loop :melody do
  use_synth :prophet
  play (scale :c4, :minor_pentatonic).choose, release: 0.3, amp: 0.5, cutoff: 90
  sleep (ring 0.5, 0.5, 1).tick
end

    フェーズ4: メロディを止め、キックとハイハットだけに

    use_bpm 120

live_loop :hihat do
  sample :hat_snap, amp: 0.4
  sleep 0.5
end

live_loop :kick do
  sample :bd_haus
  sleep 1
end

live_loop :snare do
  sleep 1
  sample :sn_dub, amp: 0
  sleep 1
end

live_loop :bass do
  sleep 0.5
end

live_loop :melody do
  sleep 0.5
end

    フェーズ4ではスネアを amp: 0 でミュートし、ベースとメロディは sleep だけにして無音化しています。ハイハットとキックだけが残り、余韻を持って終わります。

    演習6（発展）: パフォーマンス構成の設計¶

    解答例: テーマ「夜の街」

    使用素材¶

    種類 素材
    シンセ :tb303（ベース）、:prophet（メロディ）、:dark_ambience（パッド）
    サンプル :bd_haus、:sn_dub、:hat_snap
    エフェクト :reverb、:echo、:lpf

    展開計画¶

    時間 フェーズ 操作
    0:00〜0:30 導入 パッドだけ（長い音、リバーブ深め）
    0:30〜1:00 構築 キック追加、ハイハット追加
    1:00〜1:30 展開1 ベース追加、スネア追加
    1:30〜2:00 展開2 メロディ追加、エコー付き
    2:00〜2:30 ブレイク キックとベースをミュート、メロディとパッドだけ
    2:30〜2:45 再構築 キックとベース復帰、全パート
    2:45〜3:00 終結 メロディ→スネア→ハイハットの順にミュート、パッドで終わる

    コード（フル構成時）¶

    use_bpm 118

live_loop :metro do
  cue :beat
  sleep 0.5
end

# パッド（最初から最後まで鳴っている）
live_loop :pad do
  use_synth :dark_ambience
  with_fx :reverb, mix: 0.7, room: 0.9 do
    play :e3, attack: 2, sustain: 4, release: 2, amp: 0.4, cutoff: 80
    sleep 8
  end
end

# キック
live_loop :kick do
  sync :beat
  sample :bd_haus, amp: 1 if (ring 1, 0, 0, 0, 1, 0, 0, 0).tick == 1
end

# スネア
live_loop :snare do
  sync :beat
  with_fx :reverb, mix: 0.3 do
    sample :sn_dub, amp: 1 if (ring 0, 0, 1, 0, 0, 0, 1, 0).tick == 1
  end
end

# ハイハット
live_loop :hihat do
  sync :beat
  sample :hat_snap, amp: (ring 0.5, 0.2, 0.4, 0.2).tick
end

# ベース
live_loop :bass do
  sync :beat
  use_synth :tb303
  with_fx :lpf, cutoff: 80 do
    play (ring :e2, :e2, :g2, :a2, :e2, :e2, :b1, :c2).tick,
         release: 0.3, amp: 0.8
  end
end

# メロディ
live_loop :melody do
  use_synth :prophet
  with_fx :echo, phase: 0.75, mix: 0.3 do
    play (scale :e4, :minor_pentatonic).choose,
         release: 0.3, amp: 0.5, cutoff: 90
    sleep (ring 0.5, 0.5, 1, 0.25, 0.25).tick
  end
end

    演奏の際は、最初 :pad だけを含むコードで開始し、展開計画に従ってパートを段階的に追加していきます。ミュートするときは amp: を 0 に変えて「Run」を押します。
