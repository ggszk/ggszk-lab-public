    Lesson 5 演習問題¶

    演習1: cutoff の聞き比べ¶

    :saw シンセで C4 の音を鳴らし、cutoff を 130, 100, 80, 60 と変えて聞き比べなさい。

    1. それぞれの音色の印象を自分の言葉で記述する
    2. cutoff: 60 のとき、Lesson 3 で聞いた :beep（サイン波）シンセの音と比べてみる。似ている理由を Lesson 4 の倍音理論を使って説明しなさい

    演習2: シンセごとのフィルター効果を比較する¶

    以下の3つのシンセで同じ音（C4）を鳴らし、cutoff: 130 と cutoff: 70 の音色変化の大きさを比較しなさい。

    • :saw
    • :square

    • :tri

    • どのシンセが最もフィルターの効果が大きいか

    • どのシンセが最も変化が小さいか
    • Lesson 4 で学んだ各波形の倍音構成（ノコギリ波: 全倍音、矩形波: 奇数次のみ、三角波: 奇数次で \(1/k^2\) 減衰）から、その理由を説明しなさい

    演習3: パラメータを組み合わせた音作り¶

    :prophet シンセを使い、以下の条件で暖かいパッド風の音を作りなさい。

    • 3つの音（C3, E3, G3）を同時に鳴らす（和音）
    • cutoff を 60〜90 の範囲で調整し、好みの柔らかさにする
    • res を 0.1〜0.5 の範囲で調整し、音の癖を加える
    • sustain と release を長め（各 2〜4 拍）にする

    最終的に選んだパラメータの値と、その音色の印象を記述しなさい。

    演習4: リズミカルなフィルターパターン¶

    :tb303 シンセと live_loop を使い、以下の条件でフィルターパターンを作りなさい。

    1. 同じ音程（例: C2）を sleep 0.25 で繰り返す
    2. 4つの音ごとに cutoff の値を変える（例: 100, 70, 90, 60）
    3. res は 0.6〜0.8 程度に固定する

    ヒント: 配列と .zip を使うと簡潔に書けます。.zip は2つの配列を1つにまとめるメソッドで、Python の zip() と同じ働きです。

    cutoffs = [100, 70, 90, 60]
amps = [0.5, 0.3, 0.4, 0.2]

cutoffs.zip(amps).each do |c, a|
  # c と a にそれぞれの値が入る
end

    さらに余裕があれば、use_bpm でテンポを変えたり、cutoff の値のパターンを変えたりして、印象の違いを試しなさい。

    演習5: さまざまなシンセの探索¶

    以下のシンセから2つ以上を選び、cutoff と res を変えながら音色を探索しなさい。

    • :prophet — 温かみのあるアナログシンセ風
    • :tb303 — テクノの定番アシッドベースシンセ
    • :zawa — うねりのある独特の音
    • :blade — 透明感のある幻想的な音
    • :supersaw — 厚みのあるデチューンされた音

    各シンセについて以下を記録すること。

    1. cutoff を変えたときの音色変化の大きさ（大 / 中 / 小）
    2. res を変えたときの音色変化の大きさ（大 / 中 / 小）
    3. rrand(min, max) を使って cutoff をランダムに変えるとどんな効果があるか
    # rrand の使い方の例
use_synth :prophet

live_loop :explore do
  play :c3, cutoff: rrand(60, 120), res: 0.7, sustain: 0.5, release: 0.5, amp: 0.5
  sleep 0.5
end

    演習6（発展）: tb303 でアシッドベースラインを作る¶

    :tb303 を使い、以下の手順でアシッドベースラインを作りなさい。

    1. まず、以下のコードを実行して ring と .tick / .look の動作を確認する
    use_synth :tb303
use_bpm 130

live_loop :acid do
  notes = (ring :c2, :c2, :eb2, :c2, :f2, :c2, :g2, :c2)
  cutoffs = (ring 90, 70, 100, 60, 110, 80, 120, 70)

  play notes.tick, cutoff: cutoffs.look, res: 0.8,
       release: 0.2, amp: 0.5
  sleep 0.25
end

    ring は末尾に達すると先頭に戻る配列です。.tick は呼ぶたびにインデックスが1つ進み、.look は現在のインデックスの値を返します（リングと tick/look の詳細は Lesson 7 で扱います）。

    1. 音のパターン（notes）を変えてオリジナルのベースラインを作る
    2. cutoff のパターン（cutoffs）を変えて、音色の動きを調整する
    3. res の値を変えてレゾナンスの効果を確認する
    4. 最終的に気に入ったパターンのコードと、その音色の印象を記述する
