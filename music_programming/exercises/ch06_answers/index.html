    Lesson 6 演習解答¶

    演習1: 解答例¶

    手計算:

    1. MIDI 69: \(f = 440 \times 2^{(69-69)/12} = 440 \times 2^0 = 440 \times 1 = 440\) Hz
    2. MIDI 81: \(f = 440 \times 2^{(81-69)/12} = 440 \times 2^1 = 880\) Hz
    3. MIDI 60: \(f = 440 \times 2^{(60-69)/12} = 440 \times 2^{-9/12} = 440 \times 2^{-3/4} \approx 440 \times 0.5946 \approx 261.6\) Hz
    4. MIDI 57: \(f = 440 \times 2^{(57-69)/12} = 440 \times 2^{-1} = 220\) Hz
    from audio_lib import note_to_frequency

for midi_num in [69, 81, 60, 57]:
    freq = note_to_frequency(midi_num)
    print(f"MIDI {midi_num} → {freq:.2f} Hz")

    MIDI 69, 81, 57 は A4 から 0, +12, -12 半音なのでオクターブの整数倍。MIDI 60 だけ \(2^{-3/4}\) の計算が必要。

    演習2: 解答例¶

    1. ノコギリ波でスケールを鳴らす¶

    from audio_lib import sawtooth_wave, sine_wave, note_to_frequency, AudioSignal
from audio_lib.notebook import play_sound
from IPython.display import display
import numpy as np

c_major = [60, 62, 64, 65, 67, 69, 71, 72]
dur = 0.4

parts = []
for midi_num in c_major:
    freq = note_to_frequency(midi_num)
    sig = sawtooth_wave(freq, dur)
    parts.append(sig.data)

scale_data = np.concatenate(parts)
scale_signal = AudioSignal(scale_data, 44100)
display(play_sound(scale_signal, "C メジャースケール（ノコギリ波）"))

    2. 聞こえ方の違い¶

    サイン波は素朴な「ピー」という音で、ノコギリ波は明るく鋭い音。Lesson 4 で学んだとおり、サイン波は基本波のみで倍音がなく、ノコギリ波はすべての整数次倍音を \(1/k\) の振幅で含む。倍音の豊かさが音色の明るさや鋭さの違いになっている。

    3. A マイナースケール¶

    a_minor = [57, 59, 60, 62, 64, 65, 67, 69]
note_names = ["ラ", "シ", "ド", "レ", "ミ", "ファ", "ソ", "ラ"]

parts = []
for midi_num in a_minor:
    freq = note_to_frequency(midi_num)
    sig = sine_wave(freq, dur)
    parts.append(sig.data)

scale_data = np.concatenate(parts)
scale_signal = AudioSignal(scale_data, 44100)
display(play_sound(scale_signal, "A マイナースケール"))

    A マイナースケールは C メジャースケールと同じ音を使うが、ラ（A）から始めるため暗い印象になる。これを平行調の関係と呼ぶ。

    演習3: 解答例¶

    from audio_lib import sine_wave, note_to_frequency, AudioSignal
from audio_lib.notebook import play_sound
from IPython.display import display

f0 = 440  # A4
dur = 2.0

intervals = [
    ("完全5度", 7),
    ("長3度", 4),
    ("短3度", 3),
    ("オクターブ", 12),
]

for name, semitones in intervals:
    f1 = f0
    f2 = f0 * 2 ** (semitones / 12)
    sig1 = sine_wave(f1, dur)
    sig2 = sine_wave(f2, dur)
    mixed = AudioSignal((sig1.data + sig2.data) / 2, 44100)
    display(play_sound(mixed, f"{name}: {f1:.0f} Hz + {f2:.1f} Hz"))

    記述例: - 完全5度: 明るく安定した響き。協和して心地よい - 長3度: 明るく温かい響き。メジャーコードの基本 - 短3度: やや暗く、物悲しい響き。マイナーコードの基本 - オクターブ: 2つの音が溶け合い、ほとんど1つの音に聞こえる

    演習4: 解答例¶

    import numpy as np
from audio_lib import sine_wave, sawtooth_wave, AudioSignal
from audio_lib.notebook import play_sound
from IPython.display import display

f0 = 440

# 平均律と純正律の長3度
f_equal = f0 * 2 ** (4/12)   # 554.37 Hz
f_just  = f0 * 5 / 4         # 550.00 Hz

# サイン波で聞き比べ
sig_base = sine_wave(f0, 3.0)
sig_equal = sine_wave(f_equal, 3.0)
sig_just  = sine_wave(f_just, 3.0)

mixed_equal = AudioSignal((sig_base.data + sig_equal.data) / 2, 44100)
mixed_just  = AudioSignal((sig_base.data + sig_just.data) / 2, 44100)

display(play_sound(mixed_equal, f"平均律の長3度: 440 + {f_equal:.1f} Hz"))
display(play_sound(mixed_just,  f"純正律の長3度: 440 + {f_just:.1f} Hz"))

# ノコギリ波でも聞き比べ
sig_base_saw = sawtooth_wave(f0, 3.0)
sig_equal_saw = sawtooth_wave(f_equal, 3.0)
sig_just_saw  = sawtooth_wave(f_just, 3.0)

mixed_equal_saw = AudioSignal((sig_base_saw.data + sig_equal_saw.data) / 2, 44100)
mixed_just_saw  = AudioSignal((sig_base_saw.data + sig_just_saw.data) / 2, 44100)

display(play_sound(mixed_equal_saw, f"平均律の長3度（ノコギリ波）"))
display(play_sound(mixed_just_saw,  f"純正律の長3度（ノコギリ波）"))

    周波数の差:

    print(f"平均律: {f_equal:.2f} Hz")
print(f"純正律: {f_just:.2f} Hz")
print(f"差: {abs(f_equal - f_just):.2f} Hz")

    差は約 4.37 Hz。純正律のほうが澄んだ響きで、うなり（ビート）が少ない。ノコギリ波で聞くと倍音同士の干渉が増えるため、差がよりはっきりわかる。

    演習5: 解答例¶

    import numpy as np
import matplotlib.pyplot as plt
from audio_lib import note_to_frequency, number_to_note_name

midi_range = np.arange(21, 109)
freqs = [note_to_frequency(n) for n in midi_range]

# A の位置（各オクターブ）
a_positions = [21, 33, 45, 57, 69, 81, 93, 105]

fig, axes = plt.subplots(2, 1, figsize=(12, 8))

# 線形スケール
axes[0].plot(midi_range, freqs)
axes[0].set_ylabel("周波数 (Hz)")
axes[0].set_title("線形スケール")
axes[0].grid(True, alpha=0.3)
for pos in a_positions:
    axes[0].axvline(x=pos, color='r', alpha=0.3, linestyle='--')
    axes[0].annotate(number_to_note_name(pos), (pos, note_to_frequency(pos)),
                     textcoords="offset points", xytext=(5, 5), fontsize=8)

# 対数スケール
axes[1].semilogy(midi_range, freqs)
axes[1].set_xlabel("MIDI ノート番号")
axes[1].set_ylabel("周波数 (Hz)")
axes[1].set_title("対数スケール")
axes[1].grid(True, alpha=0.3, which='both')
for pos in a_positions:
    axes[1].axvline(x=pos, color='r', alpha=0.3, linestyle='--')
    axes[1].annotate(number_to_note_name(pos), (pos, note_to_frequency(pos)),
                     textcoords="offset points", xytext=(5, 5), fontsize=8)

plt.tight_layout()
plt.show()

    線形スケールでは高音域が急激に上昇する指数曲線、対数スケールでは直線になる。これは MIDI 番号と周波数が \(f = 440 \times 2^{(n-69)/12}\) という指数関数の関係にあるため。

    演習6: 解答例¶

    1. ピタゴラス音律の実装¶

    import numpy as np
from audio_lib import sine_wave, AudioSignal
from audio_lib.notebook import play_sound
from IPython.display import display

def pythagorean_scale(base_freq):
    """ピタゴラス音律の C メジャースケールを生成"""
    # 5度圏で音を生成: F-C-G-D-A-E-B
    # C を基準に、5度（×3/2）を積み重ねる
    fifth = 3 / 2

    # C を 1 として、5度圏で各音の周波数比を求める
    ratios = {}
    ratios['C'] = 1.0
    ratios['G'] = fifth                        # 3/2
    ratios['D'] = fifth ** 2 / 2               # 9/8（オクターブ下に戻す）
    ratios['A'] = fifth ** 3 / 2               # 27/16
    ratios['E'] = fifth ** 4 / 4               # 81/64
    ratios['B'] = fifth ** 5 / 4               # 243/128
    ratios['F'] = 1 / fifth * 2                # 4/3（5度下 = 4度上）

    # C メジャースケール順に並べる
    scale_order = ['C', 'D', 'E', 'F', 'G', 'A', 'B', 'C_high']
    ratios['C_high'] = 2.0

    freqs = [base_freq * ratios[note] for note in scale_order]
    return freqs, scale_order

# ピタゴラス音律
pyth_freqs, names = pythagorean_scale(261.63)  # C4 基準

# 平均律
from audio_lib import note_to_frequency
equal_midi = [60, 62, 64, 65, 67, 69, 71, 72]
equal_freqs = [note_to_frequency(n) for n in equal_midi]

# 比較表示
print(f"{'音名':<8} {'ピタゴラス':>12} {'平均律':>12} {'比率':>8}")
print("-" * 48)
for name, pf, ef in zip(names, pyth_freqs, equal_freqs):
    ratio = pf / ef
    print(f"{name:<8} {pf:>12.2f} Hz {ef:>12.2f} Hz {ratio:>8.5f}")

    2. ピタゴラスコンマ¶

    pythagorean_comma = (3/2) ** 12 / 2 ** 7
print(f"ピタゴラスコンマ: {pythagorean_comma:.5f}")
print(f"百分率: {(pythagorean_comma - 1) * 100:.2f}%")

    \((3/2)^{12} = 129.746\) だが \(2^7 = 128\) なので、12回の完全5度で元に戻ると約 1.4% ずれる。これがピタゴラスコンマ。

    3. 聞き比べ¶

    dur = 0.4

# ピタゴラス音律のスケール
parts_pyth = []
for freq in pyth_freqs:
    sig = sine_wave(freq, dur)
    parts_pyth.append(sig.data)
pyth_signal = AudioSignal(np.concatenate(parts_pyth), 44100)

# 平均律のスケール
parts_equal = []
for freq in equal_freqs:
    sig = sine_wave(freq, dur)
    parts_equal.append(sig.data)
equal_signal = AudioSignal(np.concatenate(parts_equal), 44100)

display(play_sound(pyth_signal,  "ピタゴラス音律"))
display(play_sound(equal_signal, "平均律"))

    ピタゴラス音律はメロディが伸びやかに聞こえるが、長3度（E）が平均律より高く、和音では硬い印象になる。平均律は各音の間隔が均等で、どの調に転調しても同じように響く。
