    付録A: Google Colab と audio_lib のセットアップ¶

    本書の Python 回（Lesson 1, 2, 4, 6, 8, 9, 11, 13）は Google Colab 上で実行します。ブラウザだけで動くので、Python のインストールや環境構築は不要です。

    A.1 Google Colab を開く¶

    1. Google アカウントにログインした状態で https://colab.research.google.com/ にアクセスします
    2. 「ノートブックを新規作成」を選びます
    3. コードセル（灰色の入力欄）が表示されたら準備完了です

    Colab の基本操作は次のとおりです。

    操作 方法
    セルの実行 Shift + Enter またはセル左の再生ボタン
    セルの追加 上部メニューの「+ コード」または「+ テキスト」
    すべて実行 メニュー「ランタイム → すべてのセルを実行」
    ランタイムの再起動 メニュー「ランタイム → ランタイムを再起動」

    A.2 audio_lib のインストール¶

    各レッスンの最初に、以下のセットアップセルを実行してください。本書の付属ライブラリ audio_lib がインストールされ、音の生成・再生・可視化がすぐに使えるようになります。

    # --- 最初に1回だけ実行 ---
import sys
try:
    import google.colab
    !pip install -q japanize-matplotlib
    !git clone -q https://github.com/ggszk/simple-sound-programming.git
    sys.path.append('/content/simple-sound-programming')
except ImportError:
    # ローカル環境の場合
    sys.path.append('..')

from audio_lib.notebook import setup_environment
setup_environment()

    「Google Colab環境セットアップ完了」と表示されれば成功です。

    注意: Colab のランタイムを再起動した場合は、このセルをもう一度実行する必要があります。

    A.3 audio_lib の主な機能¶

    audio_lib は本書のために用意した教育用ライブラリです。以下の機能を提供します。

    波形生成（関数）¶

    from audio_lib import sine_wave, sawtooth_wave, square_wave, triangle_wave

signal = sine_wave(frequency=440, duration=1.0)  # サイン波

    sine_wave() などの関数は周波数と長さを指定するだけで波形を生成します。戻り値は AudioSignal オブジェクトで、音のデータとサンプリングレートをセットで保持しています。

    音の再生と可視化（ノートブック用）¶

    from audio_lib.notebook import play_sound, plot_waveform, plot_spectrum
from IPython.display import display

display(play_sound(signal, "440Hz サイン波"))  # 音を再生
plot_waveform(signal, duration=0.01)            # 波形を表示
plot_spectrum(signal)                           # スペクトラムを表示

    play_sound() はノートブック上に再生プレーヤーを表示します。display() で囲むのを忘れないようにしてください。

    音名・周波数の変換¶

    from audio_lib import note_to_frequency, note_name_to_number

midi_num = note_name_to_number("A4")      # 69
freq = note_to_frequency(midi_num)         # 440.0

    エンベロープ¶

    from audio_lib import adsr

envelope = adsr(duration=1.0, attack=0.1, decay=0.2, sustain=0.7, release=0.3)
sound = signal * envelope  # 音量が時間変化する音に

    ファイルへの保存¶

    from audio_lib import save_audio

save_audio("my_sound.wav", signal)

    これ以外にもフィルター、エフェクト、楽器、シーケンサーなどの機能があります。各レッスンで必要に応じて紹介します。

    A.4 Colab を使うときの注意点¶

    ランタイムの接続切れ¶

    Colab は一定時間操作がないとランタイムが切断されます。切断された場合は「ランタイム → ランタイムを再起動」で復帰し、セットアップセルから再実行してください。

    ファイルの保存¶

    Colab 上で生成した WAV ファイルなどは、ランタイムの切断時に失われます。手元に残したい場合は、サイドバーのファイル一覧からダウンロードするか、Google Drive にマウントして保存してください。

    # Google Drive にマウントする場合
from google.colab import drive
drive.mount('/content/drive')

# Drive に保存
save_audio("/content/drive/MyDrive/my_sound.wav", signal)

    音が鳴らない場合¶

    • ブラウザのタブがアクティブになっていることを確認してください
    • ブラウザの音量設定や OS の音量がミュートになっていないか確認してください
    • display(play_sound(...)) の display() が抜けていないか確認してください
