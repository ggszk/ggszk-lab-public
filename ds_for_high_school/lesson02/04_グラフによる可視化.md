# グラフによる可視化

## 🟪 棒グラフ（カテゴリごとの数を見る）

### CODAPでの操作

1. グラフを開く（上のメニュー →「グラフ」）
2. **X軸にカテゴリ変数**（例：性別）をドラッグ
3. カテゴリの値ごとの棒グラフができる
4. グラフ右の「ものさしマーク（統計量）」をクリック
5. 「カウント」や「百分率」をクリックすると、それぞれが棒の上に表示される
6. 別の属性を**グラフのプロット領域（棒の内側）**にドラッグすると、その値で色分けされる（凡例）
7. グラフ上部の文字（最初はデータ名）をクリックすると、グラフ名を変更できる

→ 何か棒グラフを作ってみよう

## 🟦 ヒストグラム（分布を見る）

**何を表す？** … 数値データの分布の形（山の数・広がり・偏り）。似た値を階級にまとめ、その件数を棒で表示。

**読み取りポイント**
- よく出てくる値がどこに集中しているか
- 左右対称か、偏っているか（右にのびる＝右に偏り）

### CODAPでの操作

1. グラフを開く
2. **X軸に数値データ**（例：睡眠時間）をドラッグ
3. グラフ右のグラフマークをクリック
4. 形状で「階級に分類する」を選び、「ドットを融合する」にチェック → ヒストグラムになる（階級幅も変更できる）

→ 何かヒストグラムを作ってみよう

## 🟩 散布図（2つの数の関係を見る）

**何を表す？** … 2つの数値データの関係（相関）を、点の位置で表す。

**読み取りポイント**
- 右上がり → 正の相関（片方が増えるともう片方も増える）
- 右下がり → 負の相関（逆に動く）
- バラバラ → 相関なし

### CODAPでの操作

1. グラフを開く
2. **X軸に数値データA、Y軸に数値データB** をドラッグ
3. 点の広がり方を観察する

→ 何か散布図を作ってみよう

## 🟥 箱ひげ図（ばらつき・中央値を見る）

**何を表す？** … データのばらつき・中心・外れ値を1つの箱で表す。四分位数（25%・50%・75%）を表示。

**読み取りポイント**
- 中央の線：中央値（50%地点）
- 箱の長さ：データの広がり
- 点：外れ値（極端に大きい/小さい）

### CODAPでの操作

1. グラフを開く
2. **X軸にカテゴリ変数**（例：性別）
3. **Y軸に数値変数**（例：睡眠時間）
4. グラフ右の「ものさし（統計量）」をクリック →「箱ひげ図」を選ぶ

→ 何か箱ひげ図を作ってみよう

## 💡 まとめ：グラフの使い分け

| グラフ | 主な用途 | 軸の指定 |
|---|---|---|
| 棒グラフ | カテゴリごとの数を見る | X軸にカテゴリ |
| ヒストグラム | 1つの数値の分布を見る | X軸に数値だけ |
| 散布図 | 2つの数値の関係（相関）を見る | X軸・Y軸に数値 |
| 箱ひげ図 | グループごとのばらつきを比べる | X軸：カテゴリ／Y軸：数値 |
