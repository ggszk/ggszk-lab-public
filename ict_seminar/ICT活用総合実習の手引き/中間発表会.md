# 中間発表会

- **参加者**
    - ゼミメンバー＋副査の先生
- **実施日・発表時間**
    - 夏休み明けの9月下旬-10月初旬
    - 1件　発表10分（1人） or 最大20分（2人）＋質疑10分
- **発表内容**
    - タイトルは，実習テーマ名とする
    - 背景と課題
    - 課題解決のアプローチ（課題を解決するための方法など）
    - 現在の到達点
    - 今後の計画
- **評価**
    - 全体の20%が中間発表による評価になる
    - 副査からの評価が反映される
    - 下の評価観点で評価する
        - （ただし，観点「評価」は中間発表では重視しない）

| **評価観点** | **観点の説明** |
| --- | --- |
| テーマ設定 | テーマの重要性・新規性・チャレンジ |
| 成果物 | 作られた成果物の質と量 |
| 計画性 | 計画の作成と実行が適切か |
| 評価 | 課題解決を適切に評価しているか |
| 発表 | わかりやすく説得力があるか |

### 中間報告までに終えるべきこと

- テーマの名前が決定
- **目的と課題**を明確に
- 使用するデータが決定
- 計画が作られている
    - （アウトプットは無理しない）
