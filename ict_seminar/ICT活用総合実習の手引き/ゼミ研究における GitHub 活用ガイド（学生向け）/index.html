    ゼミ研究における GitHub 活用ガイド（学生向け）¶

    このゼミでは，研究の進行・成果管理のために GitHub を利用します（2026年度より）．

    GitHub は「提出のため」ではなく，研究を進めるための作業環境として使います．

    全体の流れ（重要）¶

    1. テーマが確定する
    2. 教員が 研究テーマ用の GitHub リポジトリを作成する
    3. 学生はそのリポジトリで研究を進める
    4. 中間・最終などの節目で milestones/ を更新する

    ※ 学生が自分でリポジトリを作成する必要はありません．

    1. リポジトリについて¶

    • 1つの研究テーマにつき，1つのリポジトリを使います
    • リポジトリは，ゼミ用テンプレートから作成されています
    • 教員が作成後，学生を collaborator（編集可）として追加します

    リポジトリの権限について¶

    • 各研究テーマのリポジトリは，ゼミ学生全員が閲覧可能
    • 編集（push）ができるのは，当該テーマの担当学生のみです．
    • 他のゼミ生は，研究の進め方を参考にする目的で閲覧してください．

    2. 最初にやること（重要）¶

    リポジトリにアクセスできるようになったら，以下の3つを最初に確認・記入してください．

    ①SEMINAR.mdを読む¶

    • このリポジトリの使い方
    • マイルストーンの考え方
    • 生成AIの利用方針

    が書かれています．最初に必ず一度読みましょう．

    ②milestones/01_proposal/README.mdを書く¶

    • テーマ決定時点での整理を書きます
    • スライドや資料は不要です
    • 箇条書きで構いません

    👉 「今，何をやると決めたか」を残すことが目的です．

    ③00_context/context.mdを書く¶

    • 研究の目的・前提・制約を書きます
    • 生成AIを使う際に，文脈を理解させるための情報になります
    • 人に読ませるための文章でなくて構いません
    • 初期作成以降の維持には生成AIを活用して構いません

    3. 日常的な作業の進め方¶

    作業場所の基本ルール¶

    • データ：01_data/
    • 分析・実装：02_work/
    • 結果・図表：03_results/
    • 原稿・スライド：04_docs/

    👉 作業途中のファイルを milestones/ に直接置かないでください．

    GitHub の基本的な使い方¶

    • 原則として main ブランチで作業します
    • 作業が一区切りついたら commit してください
    • こまめな commit を歓迎します（完成していなくてよい）

    4. マイルストーン（節目）の扱い方¶

    milestones/ は，研究の進捗をスナップショットとして残す場所です．

    milestones/
├── 01_proposal/   ← テーマ決定
├── 02_midterm/    ← 中間報告
└── 03_final/      ← 最終報告
    • 各フォルダには README.md を置きます
    • その時点での整理・結果・課題を簡潔にまとめます

    👉 作業フォルダではありません

    5. 生成AIの利用について（要点）¶

    • 本ゼミでは，生成AIの利用を推奨します
    • 調査・実装補助・文章整理などに積極的に使ってください
    • ただし：
      • 理解していない内容をそのまま使わない
      • 自分の言葉で説明できる状態にする

    生成AIを使った場合は，README 等に簡単なメモを残してください：

    • 使用したAIツール
    • 主な利用目的
    • 特に参考になった点
    • 注意・検証した点

    6. よくある注意点¶

    • GitHub は「提出箱」ではありません
    • 途中経過が残っていることは問題ありません
    • 迷ったら，早めに相談してください

    まとめ¶

    • リポジトリは 研究テーマごとに使います
    • 最初にやることは：
      1. SEMINAR.md を読む
      2. 01_proposal/README.md を書く
      3. 00_context/context.md を書く
    • GitHub は 研究を進めるための道具です
