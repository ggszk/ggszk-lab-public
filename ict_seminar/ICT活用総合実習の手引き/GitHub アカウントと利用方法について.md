# GitHub アカウントと利用方法について

本ゼミでは，研究活動に GitHub を利用します．

多くの学生はすでに GitHub アカウントを持っていると思いますが，

**既存のアカウントをそのまま使って構いません**．

新しく作り直す必要はありません．

---

## **学生にやってもらうこと**

### **① ゼミ用メールアドレスを GitHub アカウントに追加する**

すでに持っている GitHub アカウントに，

**ゼミ用メールアドレス（xxx@ggszk.org）を追加**してください．

### **手順（概要）**

1. GitHub にログイン
2. 右上のアイコン → **Settings**
3. **Emails**
4. Add email address から
    
    ゼミ用メールアドレス（xxx@ggszk.org）を追加
    
5. 届いた確認メールで **Verify** を行う

※ 既存のメールアドレスは削除しなくて構いません．

※ どのメールを「Primary」にするかは問いません．

---

### **② GitHub のユーザー名を教員に伝える**

- GitHub の **ユーザー名（@username）** を教員に共有してください
- ゼミ用メールアドレスを追加した後に連絡してください

---

## **教員側で行う作業**

- 学生の GitHub アカウントを
    
    **ゼミの GitHub 組織（ggszk-lab）に追加**
    
- 追加作業は，**ゼミ用メールアドレス（xxx@ggszk.org）を使って行います**
- テーマが確定した後，該当する研究リポジトリに権限を設定します

---

## **なぜメールアドレスを追加するのか**

- GitHub 組織への招待を **確実に行うため**
- 個人の私用メールと，ゼミ活動を切り分けるため
- 卒業後の整理・権限管理をしやすくするため

👉 **アカウント自体は個人のもののままで問題ありません**．

ゼミ用メールアドレスは「所属確認」のために使います．

---

## **注意点**

- GitHub アカウントを持っていない場合は，新規作成してください
- アカウント名は自由ですが，極端に不適切な名前は避けてください
- 不明点があれば，早めに相談してください

---

## **Git 練習用リポジトリについて（動作確認）**

ゼミでは，研究テーマが確定する前に，

**GitHub／git の動作確認と練習**を行うための

**練習用リポジトリ**を使用します．

- このリポジトリは，GitHub アカウントが正しく使えるかを確認する目的のものです
- clone，commit，push が一度できれば十分です
- 内容は途中で止まっていても問題ありません

---

### **位置づけ（重要）**

- 練習用リポジトリ：
    
    GitHub・git の操作確認用（年度初めのみ使用）
    
- 研究用リポジトリ：
    
    テーマ確定後に，教員が別途作成します
    

👉 **練習用リポジトリと研究用リポジトリは別物**です．

---

### **やること（概要）**

- 教員から共有された練習用リポジトリを clone する
- 自分用フォルダを作成する
- README を作成し，commit / push する

これができれば，GitHub の利用準備は完了です．

---

### **注意**

- 練習用リポジトリには，研究データや個人情報を入れないでください
- 他の学生のフォルダは編集しないでください
- このリポジトリは評価対象ではありません
