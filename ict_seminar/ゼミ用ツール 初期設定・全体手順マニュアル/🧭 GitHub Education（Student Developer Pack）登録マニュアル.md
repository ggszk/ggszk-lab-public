# 🧭 GitHub Education（Student Developer Pack）登録マニュアル

## **〜 Github Copilot Pro相当 を無料で使うための手順 〜**

### **🎯 目的**

この手順は、GitHub Copilot Pro相当を**無料で使える学生向けライセンス**

（Student Developer Pack）を有効にするためのものです。

教育・研究目的で GitHub Copilotを使用する学生は、

以下の手順を順番に進めてください。

---

## **🪪 1. 前提条件**

| **項目** | **内容** |
| --- | --- |
| GitHub アカウント | 自分のアカウントを用意しておく（例：username） |
| 学校のメールアドレス | @kaishi-pu.ac.jp のような **教育機関ドメインのメール**が必要 |
| 学生証 | 本人確認のために **写真画像をアップロード**する必要あり（スマホ撮影でOK） |

> 🔸アカウントを新規作成する場合は、
> 

> https://github.com/join
> 

> にアクセスして登録してください。
> 

> ユーザー名は
> 
> 
> **実名ではなく学籍番号やハンドル名**
> 

---

## **🧩 2. GitHub Education にアクセス**

1. Webブラウザで以下のURLを開きます：
    
    👉  [https://education.github.com/benefits](https://education.github.com/benefits)
    
2. 画面右上の **「Get benefits」** ボタンをクリックします。
    
    GitHubにログインしていない場合は、ここでログインしてください。
    

---

## **🧾 3. 「Student Developer Pack」申請フォームの入力**

1. 「**I’m a student**（学生です）」を選択。
2. 以下の項目を順に入力します：

| **項目** | **入力内容** |
| --- | --- |
| School Name | 「Kaishi Professional University」または「開志専門職大学」 |
| Email address | 学校のメールアドレス（例：xxxx@kaishi-pu.ac.jp） |
| How do you plan to use GitHub? | “For university coursework and data science experiments.”（英語で簡潔にOK） |
| Proof of academic status | 学生証を撮影してアップロード（JPEGまたはPNG） |
1. 内容を確認して **「Submit your information」** を押します。

---

## **⏳ 4. 承認を待つ**

- 審査には通常 **数時間〜1営業日程度** かかります。
- 結果は GitHub に登録したメールアドレスに届きます。
- 審査状況は [https://education.github.com/benefits](https://education.github.com/benefits) で確認できます。

> ⚠️ よくある失敗：
> 
- メールアドレスが学校ドメインでない（例：Gmailなど）
- 学生証が不鮮明／期限切れ
- 名前がアカウント情報と一致していない

---

## **🚀 5. 承認後：Copilotを有効化する**

1. 承認メールが届いたら、
    
    [https://github.com/features/copilot](https://github.com/features/copilot) を開きます。
    
2. 「**Get Copilot free with GitHub Education**」という表示を確認。
3. 「Enable Copilot for your account」をクリック。
4. VSCodeを開き、Copilot拡張機能でGitHubに再ログインすれば完了です。

> ✅ 有効化後は「チャット メッセージの月間クォータに達しました」という制限が解除されます。
> 

---

## **🧭 トラブルシューティング**

| **症状** | **対応** |
| --- | --- |
| 申請から3日経ってもメールが来ない | 学生証の画像を再提出して再申請 |
| Copilotがまだ有料と出る | VSCode上で一度「Sign out」→再ログイン |
| クレジットカード入力を求められる | Student Developer Packがまだ承認されていない可能性あり |

---

## **🧩 補足：登録確認方法**

1. [https://github.com/settings/billing](https://github.com/settings/billing)
2. 「GitHub Copilot for Individuals」が **“Free (Education license)”** と表示されていればOK。
