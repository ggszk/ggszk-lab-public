    生成AIの活用方針¶

    本ゼミでは，研究・実務の現場で生成AIの利用が前提となっている現状を踏まえ，

    生成AIの利用を禁止せず，むしろ積極的な活用を推奨します．

    重要なのは「使わないこと」ではなく，上手に使い，結果に責任を持つことです．

    生成AIの利用について（基本方針）¶

    • 生成AIの利用は許可されており，制限しません
      • 要旨，中間報告書，最終報告書の作成に生成AIを利用してよい
      • プログラム作成，文章の推敲，構成整理などへの利用も可
    • 生成AIの利用を積極的に推奨します
      • 特に以下の段階での活用を推奨します：
        • 先行研究・関連技術の調査
        • 分析手法や実装方針の検討
        • 課題設定・仮説設定に関するブレインストーミング
        • エラー調査やコード理解の補助

    利用可能なAIツールについて¶

    • ゼミで契約している Google Workspace
      • Gemini Advanced
      • NotebookLM Plus
      • これらは有料サービスであり，対話内容は外部の学習に利用されません．積極的に活用してください
    • ChatGPT を利用する場合：
      • GPT-5 以降のモデルの利用を推奨
      • 無料版では GPT-5の利用回数に制限があるため，必要に応じて Plus（有料）以上の利用を推奨

    • GitHub Copilot について：

      • 大学のメールアドレスで GitHub Education が利用可能
      • Copilot Pro相当のサービスが無料で利用できるので，以下のマニュアルを参照し，登録して利用すること

      🧭 GitHub Education（Student Developer Pack）登録マニュアル

    ※ いずれのツールを利用してもよく，ツール選択自体は評価対象ではありません．

    生成AI利用に関する注意点（重要）¶

    • 生成AIは非常に有用ですが，使い方によっては学生自身の能力向上の機会を奪うリスクがあります
    • 生成AIが生成した文章・プログラム・分析案については：
      • 必ず自分の頭で理解すること
      • 自分の言葉で説明できる状態にしておくこと
    • 理解していないコードや文章を，そのまま提出・発表することは認めません

    評価の対象は，

    「AIが何を出したか」ではなく，「それをどう理解し，どう使ったか」です．

    生成AIの利用例¶

    積極的に利用してよい例

    • コードや分析処理の雛形作成
    • エラーメッセージの解釈
    • ライブラリ・APIの使い方の調査
    • README やコメントの改善
    • 分析方針・仮説案の整理

    利用してよいが，特に理解が求められる例

    • 分析結果の解釈文
    • 数式・統計手法の説明
    • 論文要約や比較整理

    そのまま使用することは不可

    • 結論・考察の丸写し
    • 理解していない分析結果の提出
    • 実験結果の捏造や都合のよい補完

    AI利用の記録について（推奨）¶

    生成AIを利用した場合は，以下のような簡単なメモを

    README や Notion ページに残すことを推奨します：

    • 使用したAIツール：
    • 主な利用目的：
    • 特に参考になった点：
    • 注意・検証した点：

    詳細なログ提出は求めませんが，透明性と振り返りを重視します．

    まとめ（ゼミとしての立場）¶

    • 生成AIは 使ってよい／使うべき道具です
    • ただし，研究の問い・判断・結論の責任は学生自身にあります
    • 「AIをどう使い，どこで疑い，どう検証したか」を重視します
