    レポート課題¶

    1. レポートの目的¶

    本レポートは，音・音楽を題材として，

    • 情報を調べる
    • 整理・分析する
    • 自分の考えを文章で表現する

    という大学での学びの基礎を身につけることを目的とする。 あわせて，後半に行う Sonic Pi を用いた音楽制作の構想資料とする。

    2. レポートのテーマ¶

    以下の いずれか1つを選んで取り組むこと。

    テーマA：「私が惹かれる音楽を，Sonic Pi で再構成するとしたら」¶

    • 好きな楽曲・アーティスト・ジャンルなどを1つ選ぶこと
    • 単なる感想や紹介ではなく，以下のような観点から整理・考察すること
      • リズムの特徴（速さ，反復，ノリなど）
      • メロディの印象（動き，繰り返し，跳躍など）
      • 雰囲気を作っている要素（音色，間，エフェクト感など）
    • すべてを再現する必要はない。 「これだけは外せない要素」を1〜2点選び， それを Sonic Pi で表すとしたらどうなりそうかを考えること

    テーマB：「コンピュータと音楽：仕組みを1つ選んで調べる」¶

    • 音楽とコンピュータに関係する仕組みを1つ選び，調べてまとめること （例）
      • BPM とは何か
      • 音程や音高が数で表される理由
      • ループ音楽の特徴
      • プログラミングで音楽を作るとはどういうことか
    • 高度な数学や専門知識は不要とする
    • 図・例・比喩などを用いて分かりやすく説明すること
    • 最後に，その仕組みを Sonic Pi での自分の制作でどう使ってみたいかを考察すること

    3. Sonic Pi との関係について（重要）¶

    本レポートでは，前半で体験した Sonic Pi を念頭に置き， 「この音楽（または仕組み）のどの要素なら Sonic Pi で表現できそうか」 を考えること。

    • Sonic Pi の文法や具体的なコードを書く必要はない
    • 完成した曲を想定する必要もない
    • 「できそうなこと／難しそうなこと」を言語化できていればよい

    ここで書くのは「予想」でよい

    予想が当たっているかどうかは評価に関係ない。 後半の制作で自分の予想を実際に検証し，最終回の演奏会・ふりかえりで答え合わせをする。 考えるときは Sonic Pi でできることカタログ と照らし合わせるとよい。

    4. レポート作成に向けて¶

    • 生成AIの利用は，調査・整理目的に限って可とする
    • レポート本文は，自分の言葉で書くこと
    • 参考文献を最低1つ以上示すこと（書籍・Web記事・動画など可）

    5. フォーマット¶

    • Microsoft Word を使用すること
    • 文字数：1200〜1600字程度
    • 構成・形式は，授業内で指示した内容に従うこと

    6. 提出方法¶

    • 指定された期日までに，指定された方法で提出すること
    • 本レポートは，後半の Sonic Pi 制作の構想資料として使用する
