    DAW とは？（と，このゼミでの位置づけ）¶

    このページでは，DAW（Digital Audio Workstation）とは何か，および本ゼミでの DAW の位置づけについて説明します。

    このゼミの音楽制作の中心は Sonic Pi です。DAW は「使ってもよいし，仕組みを知る材料にしてもよい」という補助的な位置づけです。まずはそれを押さえてください。

    DAW とは？¶

    DAW（デジタル・オーディオ・ワークステーション）とは，コンピュータ上で音楽制作を行うためのソフトウェアです。

    従来の音楽制作スタジオで使われていた，

    • ミキサー
    • マルチトラック・レコーダー
    • エフェクター
    • 音源モジュール

    といった機材を，ソフトウェアとして統合した環境と考えることができます。 現在では，個人でも比較的安価に，高品質な音楽制作が可能になっています。

    いろいろな DAW¶

    DAW にはさまざまな種類があり，用途やジャンルによって好まれるソフトが異なります。

    • 使用アーティスト数によるランキング: DAW Software | Equipboard

    Ableton Live や Logic Pro が上位に位置していますが，日本では Cubase のユーザが多いとも言われます。

    乗り換えコストの話

    DAW は操作体系・画面構成・作業の流れがソフトごとに大きく異なり，一度慣れると乗り換えのコストが高いという特徴があります。最初に選んだ DAW を長く使うことが多いので，情報量・サポート・学割の有無なども含めて選ぶとよいでしょう。

    このゼミでの DAW の位置づけ（2026年度）¶

    このゼミでは，サウンドプログラミングの中心を Sonic Pi に置いています。Sonic Pi は「プログラムで音を生成・制御する」「音楽を構造やプロセスとして扱う」ことに重点のある環境で，DAW とは別の楽器だと考えてください。

    そのうえで，DAW は次の2つの使い方ができます。

    1. 仕組みを知るための材料（テーマ B 向き） 「コンピュータでどうやって音が出て，音楽ができあがるのか」を調べるとき，DAW の画面（トラック・音源・エフェクト・書き出し）を見ると，制作の一般的な流れが具体的にイメージできます。必ずしも自分でインストールして作品を作る必要はありません。 動画や記事で構造を見るだけでも十分です。
    2. 触ってみたい人の入り口（任意） 「Sonic Pi 以外も触ってみたい」という人は，下の無料ツールから気軽に試して構いません。ただし制作の本線は Sonic Pi のままです。DAW は寄り道・比較のためのものと考えてください。

    過去の年度では

    以前の年度では，Reaper をインストールしてピアノ音源を鳴らす，といった基礎操作の体験を全員で行ったこともありました。ただ「音を鳴らす環境をひととおり触る」だけで時間がかかるため，今年度は全員一律の必修体験にはせず，上の「調べる／任意で触る」という形にしています。

    なぜ DAW を知っておくとよいか¶

    DAW にひととおり触れる（または仕組みを調べる）ことで，

    • 「音源を鳴らす」とはどういうことか
    • 音がどのように管理・再生されるか
    • サウンド制作の一般的な作業環境

    を，実感として理解できます。これは Sonic Pi でのサウンドプログラミングや，レポートのテーマ B（仕組みを調べる）を進めるうえでの土台となる経験になります。

    触ってみたい人へ：無料で始められるツール¶

    「作品を作る」より，まずは雰囲気をつかむのが目的です。有名 DAW（Ableton Live・Studio One・FL Studio など）は基本的に有料ですが，無料で試せるものや，無料トライアルのあるものがあります。

    ツール 費用 対応 向いている用途
    BandLab 完全無料（登録のみ） ブラウザ（Win/Mac 共通） 一番の入り口。インストール不要で，DAW の雰囲気を最短で体験できる
    GarageBand 無料（Mac 標準搭載） Mac Mac の人はこれが手軽。入門向けで情報も多い
    LMMS 無料（オープンソース） Win/Mac/Linux 打ち込み（ステップ入力・ソフトシンセ）中心。ボカロ・DTM 的な作り方を見たい人に。※ Mac は現状 Intel 版のみ（Apple Silicon では Rosetta 経由で動作）
    Audacity 無料 Win/Mac/Linux DAW ではなく波形エディタ。「音とは何か（波形・録音・編集）」を見るのに最適。テーマ B 向き
    REAPER 有料だが長期間試せる評価版あり・ライセンスも比較的安価 Win/Mac/Linux 本格派。動作は軽いが機能が多く，最初の一歩には少し重い

    迷ったら

    まずは BandLab をブラウザで開いてみるのがいちばんラクです（何もインストールせずに試せます）。Mac の人は GarageBand でもOK。「音そのものを観察したい」なら Audacity。ここで DAW の感じをつかんでから，本線の Sonic Pi に戻ってきてください。

    Sonic Pi との関係（まとめ）¶

    • サウンドプログラミングの中心は Sonic Pi（＝このゼミの本線）
    • DAW は 補助・導入・調査の役割（必修ではない）
    • DAW は Sonic Pi と別の楽器。両方を知ると，「プログラムで音楽を作る」ことの特徴（自由度・得意不得意）がよく見えてきます
