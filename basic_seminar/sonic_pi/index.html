    Sonic Pi でできることカタログ¶

    「Sonic Pi で何ができるのか」の早見表です。 レポートで「できそうなこと／難しそうなこと」を考えるとき，制作で「やりたいことのやり方」を探すときに使ってください。

    詳しい説明は参考書 音楽プログラミング入門 の該当章（リンク先）にあります。

    苦手なこと（正直な話）¶

    レポートの「難しそうなこと」を考えるヒントです。

    • 歌声・ボーカル：歌そのものは作れない（録音サンプルを鳴らすことはできる）
    • 生演奏の細かいニュアンス：人間の演奏の揺らぎや表情を完全に再現するのは難しい
    • 既存曲の完全コピー：耳で聴いた曲をそのまま再現するには高度な分析が必要

    ただし「完全には無理でも，要素を取り出してそれらしく表現する」のが Sonic Pi の楽しみ方です。 できない理由よりも，「どの要素なら取り出せるか」を考えてみてください。

    参考書を読むときの注意¶

    参考書には Python を使う章（Lesson 1, 2, 4, 6, 8, 9, 11, 13）もありますが，基礎ゼミでは読まなくて大丈夫です。 上の表からリンクされている Sonic Pi の章だけで制作できます。 Sonic Pi の章の中に「Python では〜」という比較が出てきたら，読み飛ばして構いません。
