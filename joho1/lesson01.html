第1回：共通テスト用プログラム表記を読む

共通テスト「情報Ⅰ」のプログラミング問題は，共通テスト用プログラム表記という 日本語ベースの表記で出題されます．

この表記には，知っておくべき事情が3つあります．

  • 高校の授業で使う言語は学校によって違う（Python・JavaScript・VBA など）ので， 共通テストはどの言語も前提にしない表記を使う
  • そのため，この表記は教科書には基本的に載っていません
  • そして，本番の問題冊子にも表記の説明は付きません

つまり，この表記に慣れているかどうかは，そのまま得点差になります． このページでは，試験と同じ表記のままプログラムを動かしながら読み方を身につけます．

1. まず動かしてみる

5人の得点の合計を求めるプログラムです． 下の「Run Code」を押すと，擬似言語のまま実行されます． """ と """ の間を書き換えて，何度でも試してください．

2. 読むときの3つのポイント

① 配列の添字は 0 から始まる

Tokuten[0] が1人目の得点です．5人なら Tokuten[0] から Tokuten[4] まで． 配列名の先頭は大文字（Tokuten），ふつうの変数は小文字始まり（goukei）というのが表記の約束です．

②「4 まで」は 4 を含む

i を 0 から 4 まで の i は 0, 1, 2, 3, 4 の5回動きます． ここは間違えやすいので，あとで実際に確かめます．

③ ｜ と ⎿ が「繰り返しの中身」を表す

Python のインデントにあたるものです．⎿ はその制御文の終わりを示します． 入れ子になると ｜ ｜ のようにマーカーが重なり，マーカーの数が深さになります．

3. 変数の動きを目で見る（トレース）

試験でプログラムを読むときに実際にやるのは，変数の値を1行ずつ追いかけることです． トレース=True を付けると，その表を出せます．

ヒント表の読み方

i が 0,1,2,3,4 と動き，最後に 5 になって繰り返しが終わることが見えます． 「4 まで」なので i が 4 のときも中身が実行され，そのあと 5 になって条件を外れる — これが「まで＝含む」の正体です．

4. 演習：平均を求める

合計 goukei から平均を求めて表示するように，____ を埋めてください．

警告演算子に注意

この表記では / が実数の除算，÷ が商（整数），% が余りです． 平均は割り切れないことがあるので，どちらを使うべきか考えてください．

ノートヒント

合計を人数で割ります．人数は 要素数(Tokuten) で求められます． 平均は小数になることがあるので ÷（商）ではなく / を使います．

解答例：

実行(""" Tokuten = [65, 80, 72, 58, 90] goukei = 0 i を 0 から 要素数(Tokuten)-1 まで 1 ずつ増やしながら繰り返す: ⎿ goukei = goukei + Tokuten[i] heikin = goukei / 要素数(Tokuten) 表示する(heikin) """) 
実行("""
Tokuten = [65, 80, 72, 58, 90]
goukei = 0
i を 0 から 要素数(Tokuten)-1 まで 1 ずつ増やしながら繰り返す:
⎿ goukei = goukei + Tokuten[i]
heikin = goukei / 要素数(Tokuten)
表示する(heikin)
""")

要素数(Tokuten) を使うと，人数が変わってもプログラムを直さずに済みます．

6. 学校で Python や JavaScript を習っている人へ

注意すべき違い：Python の range(5) は 5 を含みませんが， 擬似言語の「4 まで」は 4 を含みます．同じ5回の繰り返しでも書き方が変わります．

なお，大学入試センターの公表資料自体が，同じアルゴリズムを フローチャート・Python3・JavaScript・VBA・Scratch と対比した表を載せています． 「授業の言語は多様である」ことは，出題側の前提です．

表記の仕様は大学入試センター「令和7年度大学入学共通テスト 試作問題『情報』の概要」 （2022年11月公表）の「5．共通テスト用プログラム表記の例示」に準拠しています（2026-09-03 参照）． ただしセンターは「問題文の記述を簡潔にするなどの理由で，この説明文書の記述内容に従わない形式で 出題することもある」と明記しています．本番では問題文中の説明を優先してください．
