第1回：擬似言語と Python — 配列と繰り返し

共通テスト「情報Ⅰ」のプログラミング問題は，特定の言語ではなく共通テスト用プログラム表記（日本語ベースの擬似言語）で出題されます． この教材では，擬似言語のコードを読み解き，同じ処理を Python で動かして確認します．

1. 問題の擬似言語を読む

次のプログラムは，5人の生徒の得点の合計を求めるものです．

Tokuten = [65, 80, 72, 58, 90]
gokei = 0
i を 0 から 4 まで 1 ずつ増やしながら繰り返す：
⎿ gokei = gokei + Tokuten[i]
表示する(gokei)

読むときのポイント：

  • Tokuten = [...] — 配列（Python のリストに相当）
  • i を 0 から 4 まで…繰り返す — 4 を含むことに注意（Python の range(5) に相当）
  • ⎿ — 繰り返しの中身（インデント）を表す

i を 0 から 4 まで 1 ずつ増やしながら繰り返す for i in range(5):

「まで」はその値を含む，range() は終わりの値を含まない．ここが最初のつまずきどころです．

3. 演習：平均を求める

合計 gokei から平均を求めて表示するように，____ を埋めてください．

平均は次の式で求められます：

\[ \bar{x} = \frac{1}{n} \sum_{i=0}^{n-1} x_i \]

ノートヒント

合計を人数で割ります．人数は len(tokuten) で求められます．

解答例：

tokuten = [65, 80, 72, 58, 90] gokei = 0 for i in range(5): gokei = gokei + tokuten[i] heikin = gokei / len(tokuten) print(heikin) 
tokuten = [65, 80, 72, 58, 90]
gokei = 0
for i in range(5):
    gokei = gokei + tokuten[i]
heikin = gokei / len(tokuten)
print(heikin)

4. 発展：擬似言語に戻る

Python で動きを確認したら，同じ処理を擬似言語で書くとどうなるか考えてみましょう．

Tokuten = [65, 80, 72, 58, 90]
gokei = 0
i を 0 から 4 まで 1 ずつ増やしながら繰り返す：
⎿ gokei = gokei + Tokuten[i]
heikin = gokei ÷ 要素数(Tokuten)
表示する(heikin)

試験本番で読むのは擬似言語です．「Python で動かして納得 → 擬似言語で読み直す」という往復が，この教材の基本パターンです．
