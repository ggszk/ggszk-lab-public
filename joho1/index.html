情報Ⅰ オンライン教材（デモ）

これは Quarto + Quarto Live で情報Ⅰの受験対策教材を作った場合の技術デモです． 教材そのものではなく，「この作り方で行けるか」を確かめ，プラットフォーム選定 （センターサイト / ゼミサイト / OLS / 独自）の判断材料にするために作っています．

まずは 第1回 を開いて，擬似言語のプログラムをそのまま動かしてみてください．

このデモで確認できること

  • 共通テスト用プログラム表記がページ内で動く：試験と同じ表記のまま実行・書き換えができる（→ 第1回）
  • 変数のトレース表：値の変化を1行ずつ表で出せる．試験本番でやる作業をそのまま可視化する
  • 解説ページ：Markdown が正本．数式・図・表の見た目
  • 演習ブロック：穴埋め問題＋ヒント＋解答を教材内に埋め込める
  • 同じソースからスライドも生成：（→ スライド版）

教材設計の方針（このデモが示していること）

共通テストは特定のプログラミング言語を前提にせず，共通テスト用プログラム表記で出題されます． 一方この表記は教科書には基本的に載っておらず，本番の問題冊子にも説明が付きません． 授業で Python を使ったか JavaScript を使ったかにかかわらず， 受験生にとってこの表記はほぼ初見です．

したがって教材の主役は「Python を教えること」ではなく， 擬似言語そのものを読めるようにすることに置きます． Python・JavaScript との対応表は，既習者向けの補助線として折りたたみに置く方針です．

この方針を実装するため，擬似言語を解釈して実行する小さな処理系（dncl.py）を自作し， ブラウザ内（Pyodide）で動かしています．センターが公表している二分探索の例示が そのまま実行できることを確認済みです．

この構成の位置づけ

項目 内容
正本 git 管理の .qmd（Markdown）ファイルと dncl.py
ホスティング 静的サイト（GitHub Pages / センターサイト等）でそのまま公開可
実行環境 Pyodide（ブラウザ内 WASM）．閲覧時に CDN から読み込むため通信は必要
向く用途 解説・読み物・実行しながら学ぶ演習
向かない用途 受講管理・成績蓄積（→ OLS の担当領域）

  • 確認済み：擬似言語のページ内実行，トレース表，穴埋め演習，同一ソースからのスライド生成，静的サイトとしての公開
